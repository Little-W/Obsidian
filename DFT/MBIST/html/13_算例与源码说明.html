本附录说明算例、程序与图形的复算和检查方式，不替代各专题的原理推导。随文代码包含两类检查：系统分析模型的确定性复算，以及 March 完整序列的操作计数与无故障执行检查。两类检查均不等价于目标宏的物理缺陷覆盖验证；程序结果也不等同于工业工具通过、物理缺陷完全覆盖或芯片性能改善。

3. 程序运行与检查

以下两项标准库程序需 Python 3.10 或更新版本，命令在资料根目录执行。

python src/teaching_examples.py
python src/validate_march_sequences.py

teaching_examples.py 枚举给定六实例问题的合法划分，并在声明的整数时间模型中进行精确搜索。它允许有任务运行时主动等待，但不会把结果外推为连续时间、任意任务数或任意控制器结构下的最优值。

validate_march_sequences.py 从专题 Markdown 提取完整 March 序列，在多个小容量和两种可选遍历方向下执行无故障模型。它检查初始化、读期望、操作计数和终态一致性；摘要式序列、带省略号的流程以及透明测试原理例子都不会被误认为完整算法。

4. 插图编辑与生成

全部 25 张图已改为固定连接点、水平与垂直路径、真实文字范围检查的确定性绘图。标题为 48 像素，主要文字为 32—36 像素，最小字号为 28 像素。图号和原图片路径保持不变，因此所有专题使用同一套更新后的图。

4.2 连接点与路径

节点四条边分别以 N、S、W、E 表示上、下、左、右。连接点由节点位置、边与边上比例计算，不采用手工估计的线段位置。

from svg_geometry import Figure

fig = Figure("example", "连接点示例", "从发送模块的下边连接到接收模块的上边。", 850)
fig.node("sender", 160, 240, 880, "发送模块", ["产生测试命令"])
fig.node("receiver", 160, 580, 880, "接收模块", ["接收并执行命令"])
fig.connect("command", "sender", "receiver", meaning="测试命令从发送模块到接收模块")
fig.save("example.svg")

多段路径用 edge(..., via=[...]) 明确给出水平、垂直转折点；函数拒绝斜向连接。分支和合并处需要声明 junction()，不能用没有标记的交叉来冒充连接。箭头图形尖端与标记参考位置一致，终点直接落在接收节点的边上。

更改节点尺寸或位置时，连接点会按节点重新计算；如果原转折点不再构成合法路径，需要一起调整转折点并重新检查。SVG 手工修改不会自动回写到源码，普通编辑器也不保证保持这些连接关系。

4.3 重新生成与检查

# SVG 生成只需要 Python 标准库
python src/rebuild_assets.py

# 安装精确检查与 PNG 导出的可选依赖
python -m pip install playwright
python -m playwright install chromium

# 复算分析模型、生成 SVG、检查几何、导出同环境 PNG
python src/rebuild_assets.py --png

# 检查程序自身，以及离线辅助检查页面
python src/test_geometry_checks.py
python src/build_drawing_review.py

# 只检查，不重新生成插图
python src/validate_precise_figures.py

存在系统 Chromium 时，程序会优先使用它；也可以通过 --browser /path/to/chromium 指定。检查失败会返回非零退出状态，不会把发现重叠的结果写成“通过”。

检查通过后打开 精确绘图检查.html。橙色框表示真实渲染的文字矩形及其避让范围，青色圆圈标出连接线的端点；这些辅助内容只在检查副本中出现。每张图下方还列出了连接起点、终点与含义。

普通卡片文字设置额外内边距；几何检查要求文字与连接线、箭头尖端至少间隔 10 像素，普通边框至少间隔 6 像素，小型数据矩阵中的单个数字采用 4 像素。检查同时考虑箭头尖端，不会只检查线段中心。

图形检查使用 Noto Sans CJK SC 的真实渲染范围。未分发字体文件；更换字体、修改文字或移动图形后应再次检查。PNG 为对应渲染结果的固定副本。

5. 链接公式与页面检查

python src/validate_handbook.py

# 可选：需要 Node.js 与已安装的 mathjax-full 3.x
node src/check_mathjax.js

# 可选：需要 Playwright 与 Chromium
python src/check_svg_layout.py
python src/check_html.py

# 可选：重建离线阅读网页，需要 Mistune 3.x、Node.js 和 mathjax-full
python src/render_html.py

validate_handbook.py 检查本地文档与图片引用、目录目标、参考资料编号、代码块、公式分隔、SVG 原生文字以及资料包内不含字体文件等项目。MathJax 检查只验证 TeX 转换，不是对 Obsidian 应用界面的测试；SVG 精确几何检查也不是存储器时序或电气验证。check_html.py 将本地样式和插图直接送入 Chromium 检查布局，同时静态检查页面链接；它不访问外部网站，也不测试浏览器原生文件导航。

离线网页中的公式已转换为可直接显示的数学矢量内容，不依赖浏览时联网。Markdown 中仍然保留可修改的 LaTeX。编辑 Markdown 后，应重新运行网页生成器，网页不会自动同步更新。
