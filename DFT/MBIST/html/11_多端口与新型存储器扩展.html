1.1 并发操作必须包含端口和时间信息

1.2 两类需要同时发生的激励

并发转换受阻。 假设 a=0,v=0，只有 同时发生时，v 才无法完成上升转换。序列为：

w0^A(a); w0^B(v)
w1^A(a) ‖ w1^B(v)
r1^A(a) ‖ r1^B(v)

正常结果为 (1,1)；目标故障结果为 (1,0)，端口 B 的读取发现错误。把两次写入依次执行，会改变本例的激励条件。

双激励耦合。 设两个激励单元 a,b 同时下降时把第三个单元 v 强制为 1。先建立 (a,b,v)=(1,1,0)，执行 ，再执行 r0(v)；最后读取返回 1。需要明确两个激励单元、受害单元和同时转换的方向。⁽FM18⁾

Chakraborty 与 Mazumder 的工作分别用 M1 检查双激励及并发耦合，用 M2 检查各端口的地址访问，用 M3 检查跨端口译码。以下以二进制单元说明，R 的期望值由理想模型维护。⁽FM18⁾

2.1 有序地址对遍历

按字典顺序遍历时， 的完整序列是：

(0,1), (0,2), (1,0), (1,2), (2,0), (2,1)

(i,j) 和 (j,i) 分别出现，端口角色也随之交换。共有 个有序地址对。R(i,j) 表示通过两个读端口检查当前两个地址；Dxy(i,j) 表示通过两个写端口同时写入 x,y。实际是否发生转换由进入该操作前的状态决定。

2.2 并发耦合的完整枚举教学序列

M1 的研究对象包括双激励耦合和并发转换受阻，原文使用八组操作及读取保护组织测试。⁽FM18⁾ 为逐项说明激励条件，本节给出一个初始化状态明确、可以直接运行的完整枚举教学算法。对每一个有序地址对 (i,j)、每一种目标值 (x,y)∈{00,01,10,11}、每一种其余单元背景 b∈{0,1}，独立执行：

步骤 操作 理想状态与作用
1 全部地址写入 b 为所有可能的第三受害单元建立背景
2 单独写入 i=1-x、j=1-y 保证下一次并发写入在两个位置都发生转换
3 同时读取 i,j，比较 1-x,1-y 检查激励前状态
4 同时写入 i=x、j=y 产生指定的双转换
5 读取全部地址 i,j 分别应为 x,y，其他地址仍应为 b

完整伪代码如下。

for every ordered address pair (i,j), i != j:
    for (x,y) in [(0,0),(0,1),(1,0),(1,1)]:
        for b in [0,1]:
            write_all(b)
            write(i,1-x)
            write(j,1-y)
            read_and_check(i,1-x) || read_and_check(j,1-y)
            write(i,x) || write(j,y)
            for every address v:
                expected = x if v==i else y if v==j else b
                read_and_check(v,expected)

例如 (x,y)=(0,0)、b=1 时，两个激励单元先设为 1，再同时下降。如果它们把第三个单元强制为 0，步骤 5 对该单元的 r1 立即发现错误。若同时写入使 j 不能完成下降，读取 j 时应为 0，实际为 1，也会被发现。四种 (x,y) 覆盖双转换的方向，两种 b 使被强制成 0 或 1 的第三单元都能表现出差异。

这个教学算法对固定数量端口的成本为 ：有序地址对有 个，每个组合需要整片初始化与读取。其作用是提供状态完全明确的参考执行过程，便于验证更短的双端口序列。原文 M1 通过跨地址安排读取保护达到 的测试成本，使用其压缩形式时应采用论文给定的完整故障假设和转换写操作定义。

用一个可用写端口 初始化，再依次选择每个端口 执行：

第一遍通过另一端口读取初始化结果，可以检查端口间的可访问性差异。例如，某个单元经初始化端口无法写入，却仍可通过另一端口读取，其未完成初始化的状态就可能被观察。之后的读写遍历检查该端口自己的地址唯一性与状态转换。每个端口测试结束时恢复到本轮初始背景，使下一端口从相同状态开始。⁽FM18⁾

检查不同端口的地址对应关系，可以使用逐地址单个 1 的教学序列。指定写端口 P0 和读端口 P1，对每个目标地址 j 独立执行：

P0 对全部地址写入 0
P0 向地址 j 写入 1
P1 读取全部地址 x，期望值为 (x == j)

例如 P1 把逻辑地址 0、1 对应的物理位置交换，取 j=0 后，P1 读取地址 0 将得到 0，与期望 1 不同。该序列使用 2N²+N 次单端口访问，并在程序中检查了 N=2、3、4 的全部 29 种非恒等地址置换。需要检查多个端口时，依次选择不同的写、读端口组合。

3. FeRAM 的故障与检测序列

3.1 明确存储器单元结构

电容型 FeRAM 使用铁电极化保存信息。典型读取包含感测与写回恢复，TI 的 MSP430 FRAM 技术资料明确描述了读后写回行为。⁽FM19⁾ FeFET 使用阈值电压或沟道电流区分存储状态，其读取方式和退化机制应独立建模。

对电容型 FeRAM，建议同时保存逻辑内容、极化状态、感测裕量和写回状态。软件层的一条读取指令可能由控制器完成感测与恢复两个内部阶段，因此需要明确故障位于哪个阶段。

3.2 故障类别与可观察量

故障或退化机制 模型中的关键变量 可采用的序列
写入极化转换失败 初始极化、写脉冲、最终状态 w0,w1,r1 与互补方向
读后写回失败 感测输出、恢复动作、恢复后极化 w1,r1,r1；检查第二次读取
保持退化 保持时间、温度、偏置 wb,wait(t),rb
压印 imprint 长时间保持某极性后，相反方向切换能力 wb,hold(t,T),w(1-b),r(1-b)
疲劳 fatigue 循环次数、极化切换幅度、脉冲条件 重复 w0,w1，按规定间隔测量两极性读取裕量
RAD 读取、内部写回与后续等待的联合历史 重复 rb,wait(Δt)，并测量感测裕量
fluid imprint 读取脉宽、偏压、温度、占空比与快速压印变化 固定初态下重复规定读取操作，分组检查切换和读取裕量

压印与极化循环之间的关系已有器件级研究；2025 年 RAD 论文进一步研究读后写回和操作频率相关的退化；IEDM 2025 的 fluid imprint 工作研究读取条件下的快速变化。⁽FM20⁾FM12FM13

3.3 读后写回失败的逐步例子

设读操作能正确感测 1，但应当恢复为 1 的内部写回错误地使单元成为 0。其教学序列如下。

步骤 对外操作 正常内部动作 故障内部动作 检查结果
1 w1(x) 极化写入 1 极化写入 1 建立初态
2 r1(x) 感测输出 1，随后恢复 1 感测输出 1，随后错误恢复 0 当次读通过
3 r1(x) 感测输出 1 感测输出 0 检测步骤 2 的恢复错误

这与 SRAM 的 DRDF 在对外读出轨迹上相似，但器件模型中的内部动作不同。诊断时应把感测和写回阶段分别记录。

3.4 压印检测模板

设 b 为长期保持值，t_hold 和 T_hold 为所需应力条件。

wb(x)
rb(x)
hold(t_hold, T_hold, bias_condition)
w(1-b)(x, Vwrite, twrite)
r(1-b)(x, Vread, tsample)

初始读确认写入成功；保持阶段使目标极性持续存在；互补写入检查反向切换能力；末尾读取检查切换是否完成。分别取 b=0,1。如果研究关注感测裕量，还应测量开关电荷或相应电压，并记录脉冲条件。该模板按压印检测目标推导，数值由器件规格和试验方案给出。

3.5 RAD 与循环疲劳的试验安排

一个 RAD 研究模板为：

wb(x)
重复 K 次：
    rb(x)                  # 包含器件规定的内部写回
    wait(delta_t)
记录第1次、指定中间次数及第K次的读出和裕量

扫描 delta_t，并保持读取脉冲、电压和温度可比较，可以分析操作间隔的影响。另设重复 w0,w1 的循环试验，记录实际极化切换次数。读操作自带写回的器件需要把恢复动作计入应力统计。RAD、疲劳和保持试验的操作历史应分别保存，以便解释观察到的退化。FM12

4. STT-MRAM 的故障与检测序列

4.1 模型需要包含磁性状态与概率

STT-MRAM 的磁性隧道结状态、写入电流和写入脉宽共同决定切换行为。已有缺陷研究涉及互连电阻、针孔缺陷、中间状态和磁耦合，并区分永久故障与间歇故障。2026 年的接触与互连缺陷研究进一步把磁耦合纳入 Verilog-A/SPICE 分析，再用整数线性规划构造测试。⁽FM21⁾FM09

模型类别 需要的激励 应观察的量
写入失败或切换变慢 两种切换方向、规定的写电流与脉宽 末尾读值、切换失败比例
读扰动 已知初态下重复读取 读取后的状态、首次翻转位置
保持失效 规定温度和保持时间 状态改变比例
中间磁性状态 写入后采用多个感测阈值或电阻测量 状态落入正常区间之外
邻域磁耦合 目标单元与邻居的磁性背景 各背景下的写入或读取结果
缺陷与背景共同作用 缺陷位置、阻值和磁场条件 能够激活故障的背景与操作

4.2 写脉宽与邻域背景的联合序列

设已核实的物理邻居集合为 nbr(x)，其背景为 P。对每一 P、极性 b 和写脉宽 tw 执行：

设置 nbr(x)=P
w(1-b)(x, Iinit, tinit)
r(1-b)(x)
wb(x, Itest, tw)
rb(x)

初始化采用能够建立已知状态的条件。待测写入使用 Itest,tw，最后读取检测目标转换是否完成。固定脉宽扫描邻域背景可观察背景依赖性；固定背景扫描脉宽可得到切换行为随时间的变化。若研究的正常器件也有随机失败概率，应通过重复试验比较分布，不能把单次失败直接归结为某一确定缺陷。

4.3 读扰动序列

4.3.1 应力读取次数

令 K>=1 为本轮计划检查的应力读取次数。第一次读取同时检查初始化写入的结果，并计入 K。本轮另执行一次观察读取，因此总读取次数为 K+1。对每个数据极性和物理背景独立初始化并执行：

设置目标邻域背景 P
wb(x, Iinit, tinit)
for j = 1,...,K:
    rb(x, Iread, tread)
    记录读出、是否比较失败及读取序号 j
rb(x, Iobserve, tobserve)       # 第 K+1 次读取，观察前 K 次读取留下的状态
记录全部比较结果、首次错误读取和总读取次数

Iobserve,tobserve 应按实际可用的感测模式设置。若与应力读取相同，应明确记录这一事实。若另有单独的初始化确认读取，也要将其列入物理读次数和操作历史；在该读取之后直接把历史计数清零，会改变故障模型的激励条件。

4.3.2 延迟到下一次读取才可见的故障

设 b=0，模型在第 4 次读取后把存储值改为 1，但第 4 次仍返回原值 0。取 K=4：

读取位置 返回值 读取结束后的内部状态 作用
应力读取 1 0 0 检查初始化并开始计数
应力读取 2 0 0 累积操作历史
应力读取 3 0 0 累积操作历史
应力读取 4 0 1 激活内部状态破坏
观察读取 5 1 1 与期望 0 不符，检测错误

对应执行串为 w0,r0,r0,r0,r0,r0。记录中的首次激活是第 4 次读取，首次错误返回是第 5 次读取，应分别保存。

4.3.3 观察读取产生扰动时的结果记录

所有已执行读取都按照其返回值与期望值比较，观察读取也执行相同判定。如果第 K+1 次读取返回正确值后才使内部状态改变，该变化在本轮的已返回数据中尚未出现。该实例的本轮结果为所有读取比较通过，故障检出计数为 0；单独保存的仿真内部状态可以记录这次新激活。

例如把上例的破坏阈值改为第 5 次读取，保持 K=4，五次读取均返回 0，最终内部状态为 1。本轮记录总共五次读取均返回 0，同时在仿真状态中记录最后一次读取后存储值变为 1。

有限测试的判断对象是已经执行并返回的操作，以及已经声明的故障激励范围。需要继续观察第 K+1 次读取的后果时，应把它列为下一轮应力预算的一部分并安排后续检查。需要在测试结束后恢复正常存储用途时，执行系统规定的数据重建、恢复和独立检查流程。

上述模型的可运行例子见 validate_read_disturb_and_pause.py，结果见 read_disturb_and_pause_results.json。程序检查两种极性和 K=1…64，并分别记录读出错误与读后内部状态变化。

5. RRAM 的故障与检测序列

5.1 从逻辑状态扩展到电阻区间

RRAM 可用低阻态 LRS 和高阻态 HRS 存储二进制数据，具体哪个状态代表 0 由接口定义。为了讨论模型，令正常 0、1 分别对应经过标定的电阻区间 。二者之间的未定义区间记为 ，极低或极高的异常区域另外记录。

2024 年的电流观测 DfT 工作讨论了 UWF、DeepF、URF 和 IUSF，说明只读取一个二进制结果可能丢失器件状态信息。FM11

模型 行为 所需检查
Undefined Write Fault，UWF 写入后落入未定义状态 写入后测量电流或使用多阈值感测
Deep State Fault，DeepF 电阻超过正常状态的极端范围 检查目标状态区间，必要时检查反向切换能力
Unknown Read Fault，URF 读出不稳定，可能返回随机逻辑值 重复读取与模拟状态观测
Intermittent Undefined State Fault，IUSF 间歇进入未定义状态 多轮写读与状态区间记录
背景相关多单元故障 其他单元状态改变电流通路和读取结果 指定背景下的三、四单元操作与观测

5.2 逻辑比较与状态区间检查并行执行

定义 mr_b(x)：在规定读取电压下测量电流或等效电阻，同时判断结果是否属于正常状态区间 。一个明确的检测模板是：

w0(x); mr_0(x)
w1(x); mr_1(x)
w0(x); mr_0(x)

设第二次写入后电阻落入 ，普通比较器恰好输出 1。逻辑 r1 会通过，而 mr_1 发现电阻未落入 ，从而识别异常状态。如果电阻进入异常低阻区域，二进制读取仍可能稳定，但区间检查能够区分它与正常低阻状态。

这个例子要求芯片提供电流观测、可调参考或相应测试模式。生成器需要把 mr_b 与普通 r_b 设为不同操作，并分别计算持续时间与实现成本。

5.3 数据背景相关的三、四单元模型

2026 年 RRAM 接触与互连研究指出，缺陷相关的旁路电流路径可产生背景相关的三、四单元故障。FM10

给定三个相关地址 a,b,v，可按如下模板建立一个具体模型的检测序列：

设置 a=p, b=q
wb(v)
rb(v)
执行模型规定的 op(a) 或 op(b)
rb(v)

例如，行为模型定义“a=1,b=0 时，对 a 的非状态转换写入使 v 的读电流跨过比较阈值”，就需要先建立 (a,b,v)=(1,0,0)，再执行 w1(a),r0(v)。如果错误仅体现在电阻裕量，应把末尾读取替换为 mr_0(v)。这是明确的教学模型；具体旁路电流路径和参数从目标阵列的电路分析取得。

6.5 ME6 的四单元示例：每个操作检查什么

以下轨迹由本章 NOR 定义直接计算。考虑一列 c0,c1,c2,c3，当前待测位置为 c2。

步骤 操作 理想列状态 期望结果 作用
1 w1(c2) 0010 无 建立只有待测位置为 1 的背景
2 NOR_all 0010 0 检查选中这一位置时，其逻辑 1 是否影响列计算结果
3 NOR_except(c2) 0010 1 检查排除该位置后，其余全 0 单元能否得到正确结果
4 w0(c2) 0000 无 恢复下一位置所需背景

为验证上述读出逻辑，可建立两个独立的教学行为模型：

  1. selected_one_ignored：仅 c2 为 1 且被选择时，计算结果错误地忽略它。步骤 2 返回 1，比较失败。
  2. unselected_one_contributes：c2 被排除时仍错误参与计算。步骤 3 返回 0，比较失败。

这两个模型用于解释选择集合与比较值之间的关系。电阻性开路、短路怎样产生相应输出，需要结合晶体管级模型及电气参数分析。

6.6 实现需要哪些能力

控制器需要发出双行选择、全列选择以及排除一个目标行的选择命令，并在每一次 NOR 后比较相应结果。地址译码器、读字线驱动和比较器必须支持这些操作。一次 NOR_all 可能激活多条读字线，其功耗、电流和感测时间应在电路验证中检查。

March C−8、March 8T-RPD 和 March IMC-8T 的定义来自 DATE 2024 全文。同一方向的补充文献见本章 FM23 与第 90 章的研究索引。

7. DRAM、HBM 与堆叠访问

7.1 阵列故障与堆叠互连分别检查

HBM 包含 DRAM 阵列、外围电路、层间互连和接口逻辑。阵列层需要考虑保持、刷新和读扰动；层间和接口层需要考虑连通性、时序与多线同时切换。装配前后可访问的测试接口不同，适合分阶段检查。

IEEE 1838 提供三维堆叠芯片测试访问结构，IEEE 1687 提供嵌入式仪器访问方法。具体阵列算法由目标存储器和故障模型确定。⁽FM24⁾

7.2 ColumnDisturb 对测试范围的影响

ColumnDisturb 的实验对象包含 DDR4 与 HBM2，其特点是共享列结构使影响范围可以跨越多个子阵列。针对这种模型，记录与读取的受害集合需要包含共享列区域。普通逻辑相邻地址扫描是否覆盖这一区域，应根据物理地址组织判断。FM16

第 02 章给出了 ACT、保持打开和 PRE 的参数化模板。实施时分别改变激活次数、打开时间、背景和受害集合，并保存实际刷新条件。对 HBM，测试接口能够控制的最低命令层次会直接影响可实现的应力模式。

本章双端口枚举与 IMC-8T 教学模型由 port_imc_examples.py 执行，检查结果见 port_imc_results.json。

扩展对象 新增操作或参数 直接需要验证的结果
多端口 SRAM 端口选择、并发组、相对时间 所需操作确实重叠，比较值遵从接口定义
FeRAM 感测、写回、保持、循环计数、脉冲条件 逻辑数据与恢复后状态、读取裕量

RRAM 感测参考、电流观测、状态区间 二进制结果与模拟状态是否一致

自动生成器可把这些操作定义为带参数的字母表，候选序列经过接口合法性检查后再执行故障仿真。优化目标应计算真实周期、写入应力、并发电流和实现所需状态，避免仅用一个抽象 数字代表全部代价。分组与调度中的功率计算见第 06、07 章；故障记录及修复见第 09、10 章。
