## Obsidian 与插图

将整个目录作为 Obsidian 仓库打开，或复制到已有仓库。保留 `assets/` 的相对位置，不要只移动 Markdown。公式使用 `$...$` 与 `$$...$$`，目录使用 Obsidian 标题链接。

25 张插图为采用固定连接点与正交路径的可编辑 SVG，并附同一渲染环境生成的 PNG。标题为 48 像素，主要文字为 32—36 像素，最小字号为 28 像素。文字、图形与连接线均为独立对象，未转换为轮廓，未将 PNG 包装为 SVG，也未附带字体文件。

**检查图形：[精确绘图检查.html](精确绘图检查.html)**。可以切换显示连接点、实际文字矩形与避让区域，并查看每条连接的起点、终点和含义。该辅助页面不会把检查标记写入正文插图。

25 张正文图的 792 个文字对象与 59 条连接（53 条带箭头）通过精确几何检查。检查覆盖真实渲染的文字范围、箭头尖端、模块边框、连接点、进入方向以及没有明确连接点的交叉。

直接编辑 SVG 后，重新运行源码会覆盖手工改动；需要重复生成时，请修改 `src/precise_march.py` 或 `src/precise_systems.py`。普通 SVG 编辑器不会自动维持 Python 源码中的连接点关系。

## 重新生成

```bash
python src/teaching_examples.py
python src/rebuild_assets.py --png
python src/test_geometry_checks.py
python src/build_drawing_review.py
python src/validate_march_sequences.py
python src/validate_handbook.py
```

SVG 与算例程序只需要 Python 标准库；精确文字测量、几何检查和 PNG 导出需要 Playwright 与 Chromium。完整命令和网页生成说明见 `13_算例与源码说明.md`。

## 字体与重新编辑

图形使用 Noto Sans CJK SC 的实际渲染结果检查。SVG 保留常见中文字体回退设置；更换字体后字形尺寸可能变化，应重新运行检查程序。PNG 为对应渲染结果的固定副本。
