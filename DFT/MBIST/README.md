## Obsidian 与插图

将整个解压目录作为 Obsidian 仓库打开，或把整个目录复制到已有仓库。保留 `assets/` 的相对位置，不要只移动 Markdown。公式使用 `$...$` 与 `$$...$$`，本篇目录使用 Obsidian 支持的标题链接。

25 张插图已经重新绘制为采用固定连接点和正交路径的可编辑 SVG，另附同一渲染环境生成的 PNG。标题为 48 像素，主要文字为 32—36 像素，最小字号为 28 像素。文字、图形和连接线仍是独立对象，没有转成轮廓，没有把 PNG 包装成 SVG，也没有附带字体文件。

**检查图形：[精确绘图检查.html](精确绘图检查.html)**。可以切换显示连接点、实际文字矩形与避让区域，并查看每条连接的起点、终点和含义。该辅助页面不会把检查标记写入正文插图。

当前 25 张正文图的 792 个文字对象和 59 条连接（53 条带箭头）均通过精确几何检查。方法检查真实渲染的文字范围、箭头尖端、所有模块边框、连接点、进入方向和没有明确连接点的交叉，不再只检查文字是否超过画布。

直接编辑 SVG 后，重新运行源码会覆盖手工改动；需要重复生成时，请修改 `src/precise_march.py` 或 `src/precise_systems.py`。普通 SVG 编辑器不会自动维持 Python 源码中的连接点关系。
