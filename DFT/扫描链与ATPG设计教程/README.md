# 扫描链与 ATPG 设计教程

从 [扫描链与ATPG总体架构与阅读导航](00_扫描链与ATPG总体架构与阅读导航.md) 或 `阅读入口.html` 开始。

本卷包括 1 份总览、13 个设计与研究专题、教学源码文档及 2 份附录，按测试硬件、生成算法、执行与验证组织。全部文献范围截至 2026-10-17。

`assets/` 保存可编辑 SVG，`assets/png/` 保存固定渲染副本。`src/` 保存绘图、教学和检查源码；`checks/` 保存本次实际检查结果；`examples/` 保存检测矩阵；`html/` 是离线阅读副本。

先运行 `python src/teaching_examples.py` 学习四门电路，再阅读第 13 篇的学术分析。源程序只实现小型教学模型，没有运行商业 ATPG、实际芯片测试或原论文复现。

数学使用 Obsidian 支持的行内和独立公式分隔符。不要只移动一篇 Markdown 而删除其图片目录。没有附带字体文件；修改字体、字号或文字后请重新运行几何检查。
