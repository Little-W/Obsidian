# 扫描链与 ATPG 设计

从 [扫描链与 ATPG 总体架构与阅读导航](00_扫描链与ATPG总体架构与阅读导航.md) 或 `阅读入口.html` 开始。

本目录包括 1 份总览、13 个设计与研究专题、1 份算例与源码说明及 1 份参考文献附录，按测试硬件、生成算法、执行与验证组织。文献范围截至 2026-10-17。

`assets/` 保存可编辑 SVG，`assets/png/` 保存固定渲染副本。`src/` 保存绘图、算例和检查源码；`checks/` 保存检查结果；`examples/` 保存检测矩阵；`html/` 是离线阅读副本。

运行 `python src/teaching_examples.py` 可复现四门电路、SAT 回归、扫描位序、压缩与诊断算例，第 13 篇给出相应学术分析。源程序为小型算例模型，未运行商业 ATPG、实际芯片测试或原论文复现。

数学使用 Obsidian 支持的行内和独立公式分隔符。移动 Markdown 时需保留其图片目录。目录不含字体文件；修改字体、字号或文字后应重新运行几何检查。
