# 90 参考文献与材料证据索引

[总览](00_扫描链与ATPG总体架构与阅读导航.md) · [参考文献](90_参考文献与材料证据索引.md) · [算例与源码](14_算例与源码说明.md)

## 1. 来源说明
每项记录的材料级别是现有材料取得的证据范围，不是研究质量评分。所有网址最后核查日期为 2026-10-17。正文的算例和程序结果见第 14 篇，不应归给论文作者。

<a id="s01"></a>
## S01 Bushnell 与 Agrawal 课程资料
**出处：** Auburn University，课程原始材料。**取得材料：** 基础课程。
**原始入口：** [Michael L. Bushnell 与 Vishwani D. Agrawal：VLSI Testing 课程资料](https://www.eng.auburn.edu/~vagrawal/COURSE/lectures.html)

扫描设计、组合电路测试、故障模拟及逻辑内建自测试的课程与公开资料。

<a id="s02"></a>
## S02 组合 ATPG 算法
**出处：** University of New Mexico，课程原始材料。**取得材料：** 基础课程。
**原始入口：** [Combinational ATPG：D algorithm、PODEM 与 FAN](https://ece-research.unm.edu/jimp/vlsi_test/slides/html/combinational_atpg2.html)

用于历史算法与结构搜索原理；本书的例子和程序独立编写。

<a id="s03"></a>
## S03 组合电路测试模块
**出处：** TU Delft OpenCourseWare，课程讲义。**取得材料：** 基础课程。
**原始入口：** [Module 6: Combinational Circuit Testing](https://ocw.tudelft.nl/wp-content/uploads/Module_6_Combinational_Circuit_Testing.pdf)

可控制性、可观察性及组合测试背景。

<a id="s04"></a>
## S04 TestMAX ATPG
**出处：** Synopsys，官方产品说明。**取得材料：** 厂商资料。
**原始入口：** [TestMAX ATPG](https://www.synopsys.com/implementation-and-signoff/test-automation/testmax-atpg.html)

用于核实工具功能范围；不把营销描述当作独立比较实验。

<a id="s05"></a>
## S05 Tessent TestKompress
**出处：** Siemens，官方产品说明。**取得材料：** 厂商资料。
**原始入口：** [Tessent TestKompress](https://www.siemens.com/en-us/products/ic/tessent/test/testkompress/)

嵌入式确定性测试压缩的功能背景；压缩率依具体设计而异。

<a id="s06"></a>
## S06 Tessent Streaming Scan Network
**出处：** Siemens，官方产品说明。**取得材料：** 厂商资料。
**原始入口：** [Tessent Streaming Scan Network](https://www.siemens.com/en-us/products/ic/tessent/test/streamingscan/)

芯片级扫描数据传输与核级测试架构解耦；不等同于 ATPG 算法。

<a id="s07"></a>
## S07 Pinmux 工作原理
**出处：** OpenTitan，开放硬件官方文档。**取得材料：** 实现文档。
**原始入口：** [Pinmux: Theory of Operation](https://opentitan.org/book/hw/ip/pinmux/doc/theory_of_operation.html)

Strap Sampling and TAP Isolation、Generic Pad Wrapper；只使用公开内容。

<a id="s08"></a>
## S08 RISC-V Debug Manager 工作原理
**出处：** OpenTitan，开放硬件官方文档。**取得材料：** 实现文档。
**原始入口：** [RISC-V Debug Manager: Theory of Operation](https://opentitan.org/book/hw/ip/rv_dm/doc/theory_of_operation.html)

调试访问和生命周期控制；不推断未公开的制造扫描连接。

<a id="s09"></a>
## S09 DFT 模块说明
**出处：** OpenROAD，官方软件文档。**取得材料：** 实现文档。
**原始入口：** [DFT module README](https://openroad.readthedocs.io/en/latest/main/src/dft/README.html)

scan_replace、execute_dft_plan；当前文档注明 scan_opt 尚无实际操作。

<a id="s10"></a>
## S10 FAN_ATPG
**出处：** NTU LaDS-II，作者实验室公开程序。**取得材料：** 公开代码记录。
**原始入口：** [FAN_ATPG](https://github.com/NTU-LaDS-II/FAN_ATPG)

开源算法实现入口。未运行该项目，也未将其代码复制到本目录。

<a id="s11"></a>
## S11 SmartATPG
**出处：** DAC 2024，正式会议记录。**取得材料：** 正式记录／摘要。
**原始入口：** [SmartATPG: A Learning-based Automatic Test Pattern Generation with Graph Convolutional Network and Reinforcement Learning](https://61dac.conference-program.com/presentation/?id=RESEARCH1644&sess=sess147)

未取得完整实验条件，因此不转述未核实的提速百分比。

<a id="s12"></a>
## S12 PastATPG
**出处：** DAC 2025，IEEE；DOI: 10.1109/DAC63849.2025.11132425。**取得材料：** 正式记录／摘要。
**原始入口：** [PastATPG: A Hybrid ATPG Framework for Better Test Compaction with Partial Assignment SAT](https://ieeexplore.ieee.org/document/11132425/)

部分赋值 SAT 与混合 ATPG；结合 S13 的作者程序目录核查可复现入口。

<a id="s13"></a>
## S13 PastATPG 公开仓库
**出处：** State Key Lab of Processors，作者程序。**取得材料：** 公开代码记录。
**原始入口：** [PastATPG 作者公开仓库](https://github.com/sklp-eda-lab/PastATPG)

具有求解器、基准和运行相关文件；可下载不等于已复现，原项目适用其许可证。

<a id="s14"></a>
## S14 DEFT
**出处：** Wei Li 等，arXiv:2512.23746，v1；ITC 2026 正式议程另见 S19。**取得材料：** 全文。
**原始入口：** [DEFT: Differentiable Automatic Test Pattern Generation](https://arxiv.org/html/2512.23746v1)

方法与实验分析针对这个可核实的预印本版本；不使用其页首遗留会议模板信息作为出版依据。

<a id="s15"></a>
## S15 InF-ATPG
**出处：** Bin Sun 等，arXiv:2512.00079，v1。**取得材料：** 全文／预印本。
**原始入口：** [InF-ATPG: Intelligent FFR-Driven ATPG with Advanced Circuit Representation Guided Reinforcement Learning](https://arxiv.org/html/2512.00079v1)

结果是特定基准上的回溯次数，不等于端到端执行时间；不宣称未知设计泛化。

<a id="s16"></a>
## S16 ATPG 感知扫描插入

**原始入口：** [Enhancing Test Efficiency through Automated ATPG-Aware Lightweight Scan Instrumentation](https://arxiv.org/html/2505.19418v1)

已有扫描触发器复用和轻量测试插入；功能等价、时序和面积仍需检查。
