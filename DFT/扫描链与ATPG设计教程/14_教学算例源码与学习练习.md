# 14 · 教学算例源码与学习练习

[总览](00_扫描链与ATPG总体架构与阅读导航.md) · [参考文献](90_参考文献与材料证据索引.md) · [教学与源码](14_教学算例源码与学习练习.md)

## 1. 包内程序做了什么

`src/teaching_examples.py` 使用 Python 标准库实现一个可审查的小型组合电路模型、干线与分支固定故障注入、穷举故障模拟、小型完整 DPLL SAT 求解、精确测试集合覆盖、扫描寄存器移位、未规定位填充、线性压缩和诊断等价类分析。它没有隐藏调用商业工具。

```bash
python src/teaching_examples.py
```

输出保存在 `checks/teaching_results.json`，完整检测矩阵另存为 `examples/detection_matrix.json`。随机回归采用固定种子 `20261017`，可以用参数修改电路数量：

```bash
python src/teaching_examples.py --random-circuits 40
```

## 2. 本次实际得到的结果

| 项目 | 本次结果 | 说明 |
|---|---|---|
| 教学电路目标故障 | 32 个，均可检测 | 16 个干线＋16 个门输入分支单固定故障 |
| 固定输入双电路验证 | 512 项一致 | 16 个输入 × 32 个故障，SAT 与直接模拟相符 |
| 小型随机电路回归 | 40 个电路，1374 个故障 | 每个故障的 SAT 可满足性与穷举检测存在性一致 |
| 最小向量集合 | 4 条 | 完整候选仅 16 条，使用精确枚举证明最小 |
| 立方体 | `110X` 检测 `n1/sa0` | 两种补全均单独故障模拟 |
| 扫描装入 | `1,0,1,1` 得到 `[1,1,0,1]` | Q0 靠近输入，输出在有效沿前取样 |
| 编码反例 | `111` 不可编码，`1X1` 可编码 | 两变量三输出，关系矩阵明确给出 |
| 诊断 | 32 个故障形成 18 类完整响应 | 改用每条向量单个失败标志后为 16 类 |

这些结果都是教学模型，不是 ISCAS、NVDLA 或商业芯片实验。随机电路规模很小，回归可发现实现错误，却不能证明工业性能。

## 3. 建议按顺序完成的练习

**练习一：扫描位序。** 修改目标四位状态，手算输入顺序与卸出响应。将程序错误改为逐级使用新状态，观察为什么一个沿就产生不可能的穿透行为，再恢复正确版本。

**练习二：故障激活。** 找一个能检测 `n1/sa0` 却不能检测 `n1/sa1` 的输入。分别验证干线故障和只进入 $z$ 的分支故障，解释二者不同。

**练习三：搜索与不可测试。** 对 $a\lor(a\land b)$ 的内部节点注入固定零和固定一，比较 SAT 结果。添加一个内部观察输出后，再看固定零故障是否变得可测。

**练习四：测试集合。** 将每条候选向量代价设为不同值，修改精确集合覆盖目标。比较“最少条数”与“最少总代价”的答案。

**练习五：压缩。** 交换矩阵的两行，观察哪些规定位置组合更容易编码。说明为什么交换扫描位置能改变可编码性，却不改变矩阵的整体秩。

**练习六：诊断。** 找出两个完整响应等价的故障，增加一个新观察点，重新计算它们是否还等价。再只保留失败次数，观察信息损失。

**练习七：科研复现计划。** 选择 InF-ATPG、PastATPG 或 DEFT，先填写输入电路、故障集合、硬件、训练划分、停止条件与评价指标，不急于修改算法。哪些字段只能从全文得到？哪些还需要向作者确认？

## 4. 重新生成与检查插图

全部图由 `src/generate_figures.py` 与 `src/svg_geometry.py` 生成，使用原生 SVG 文字和形状，不嵌入 PNG，不把文字转成轮廓。修改节点文案或连接后运行：

```bash
python src/generate_figures.py
python src/validate_precise_figures.py --png
python src/build_drawing_review.py
```

绘图只需要标准 Python；渲染和几何检查需要 Playwright 与 Chromium。图形检查采用浏览器实际文字矩形，检查文字、边框、箭头、连接点以及未标明的交叉。它只能验证几何布局，不能证明图中的电路连接具有电气正确性。

## 5. 重新生成离线阅读页

```bash
python src/validate_book.py
node src/check_mathjax.js
python src/render_html.py
```

HTML 导出需要 Mistune 3、Node.js 与 `mathjax-full` 3。阅读已经导出的 HTML 不需要安装这些工具，也不需要联网加载公式。Markdown 为主编辑文件；改变公式后需重新导出 HTML。

本包不包含任何字体文件。SVG 使用系统中文字体，换字体或改文字后应重新运行几何检查；PNG 是本次渲染的固定副本。
