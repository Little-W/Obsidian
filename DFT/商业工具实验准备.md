# Synopsys DFT 实验准备

术语参照：[[术语与翻译规范]]。

## 已确认的工具入口

本机通过宿主机穿通脚本调用容器中的 Synopsys 工具。已确认以下命令可用：

```bash
dc_shell -version
```

当前版本为 `V-2023.12-SP3`。实验脚本应在项目工作目录执行 `dc_shell`，不要绕过穿通脚本直接假设容器内的安装路径。

## 版本核对

在该版本中，以下 DFT Compiler 命令已确认可用：

```bash
dc_shell -x 'help set_dft_signal; help create_test_protocol; help dft_drc; help preview_dft; help insert_dft; help report_scan_path; help write_test_protocol; exit'
```

| 旧版写法 | 当前实验的首选写法 | 说明 |
| --- | --- | --- |
| `set_test_signal` | `set_dft_signal` | 定义 `ScanClock`、`ScanEnable`、`TestMode`、`Reset` 等 DFT 信号。 |
| `insert_scan` | `insert_dft` | 执行扫描插入（Scan Insertion）。 |
| `report_test -scan_path` | `report_scan_path` | 报告扫描链（Scan Chain）的端点、长度和时钟信息。 |
| `report_test -type dft_drc` | `dft_drc` | 执行 DFT 设计规则检查（DFT Design Rule Checking）。 |

> [!note] 版本差异
> `set_test_signal` 与 `insert_scan` 未出现在当前 `dc_shell V-2023.12-SP3` 的命令帮助中。旧版实验材料中的这些命令仅用于理解历史脚本；新脚本以当前版本 `help <命令>` 和 `man <命令>` 为准。

## 最小扫描实验骨架

以下脚本只展示命令顺序。顶层名、工艺库、端口名和时钟定义必须替换为当前设计的实际名称。

```tcl
read_verilog ./rtl/top.v
current_design top
link
check_design

set_dft_signal -view existing_dft -type ScanClock \
    -port scan_clk -timing {45 55}
set_dft_signal -view existing_dft -type ScanEnable \
    -port scan_enable -active_state 1
set_dft_signal -view existing_dft -type TestMode \
    -port test_mode -active_state 1
set_dft_signal -view existing_dft -type Reset \
    -port reset_n -active_state 0

create_test_protocol
dft_drc
preview_dft
insert_dft
dft_drc
report_scan_path
write_test_protocol -output ./out/top_scan.spf
```

## 实验开始前的检查

1. 确认 `target_library`、`link_library`、`search_path` 和顶层设计名称。
2. 用 `report_dft_signal` 核对扫描时钟、扫描使能、测试模式和复位端口。
3. 在插入前运行 `create_test_protocol`、`dft_drc` 和 `preview_dft`。
4. 在插入后运行 `dft_drc`、`report_scan_path`，再导出网表、测试协议与 SCANDEF。
5. 如使用 ATPG 工具，记录故障模型、故障覆盖率（Fault Coverage）、测试覆盖率（Test Coverage）和测试向量数。

## 与开源资源的关系

商业工具实验以 DFTC Lab 3 至 Lab 9 为主。先按 [[实验配套资料/README|实验配套资料]] 选择 ISCAS89 或 Logic BIST 设计，再使用本节的 DFTC 命令。[[开源实验资源/README|开源实验资源]]中的 FAN_ATPG 和 Fault 用于理解 ATPG、故障仿真和扫描插入的基础概念；其结果不能替代当前工艺库、测试协议和门级网表上的 Synopsys 检查结果。
