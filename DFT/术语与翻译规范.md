# DFT 术语与翻译规范

## 编写原则

首次出现的专业术语采用“中文（English，缩写）”形式；工具命令、报告标题、文件格式和信号名称保持原样。后文可使用已定义的中文简称或英文缩写。

报告中的原始类别标题使用反引号保留，紧随其后的中文说明使用本页规定的名称。这样既便于阅读，也便于在工具报告中检索。

## DFT 设计规则检查

| 工具报告标题 | 规范中文名称 | 说明 |
| --- | --- | --- |
| `DFT DRC` | DFT 设计规则检查（DFT Design Rule Checking） | 检查测试模式下的时钟、复位、测试控制、扫描单元和连接关系。它不同于版图规则检查。 |
| `MODELING AND USER VIOLATIONS AFFECTING SCAN INSERTION` | 建模与用户约束类违规（Modeling and User Violations Affecting Scan Insertion） | 单元模型缺失、扫描单元排除或用户约束会阻止扫描插入。 |
| `TOPOLOGY` / `TOPOLOGY VIOLATIONS` | 结构连接类违规（Topology Violations） | 描述网表连接关系的问题，例如未连接引脚或三态网络驱动不正确；此处不是版图几何问题。 |
| `PRE-DFT` / `PRE-DFT VIOLATIONS` | 扫描插入前类违规（Pre-DFT Violations） | 在插入扫描结构前发现的可测性问题，例如时钟、复位、置位或测试模式不可控。 |
| `POST-DFT` | 扫描插入后检查（Post-DFT Checking） | 针对已插入的扫描单元和扫描链进行检查。 |
| `OTHER VIOLATIONS` | 其他类违规（Other Violations） | 不属于上述类别的工具报告项；应结合违规编号和具体对象分析。 |
| `Violation Browser` | 违规浏览器（Violation Browser） | 用于定位违规对象、查看规则说明及相关连线。 |

## 扫描与测试模式

| 英文术语 | 规范中文名称 | 说明 |
| --- | --- | --- |
| Scan Insertion | 扫描插入（Scan Insertion） | 将扫描触发器、扫描端口和扫描链加入设计的过程。 |
| Scan Chain | 扫描链（Scan Chain） | 在测试模式下串接扫描触发器的移位寄存器。 |
| Test Protocol | 测试协议（Test Protocol） | 规定测试模式、扫描时钟、复位、波形和初始化序列的文件或约束集合。 |
| `test_setup` | 测试初始化段（test_setup） | 测试协议中用于建立内部测试状态的向量段。 |
| ScanClock | 扫描时钟（ScanClock） | 在扫描移位或捕获阶段使用的时钟。 |
| ScanIn / ScanOut / ScanEnable | 扫描输入 / 扫描输出 / 扫描使能（ScanIn / ScanOut / ScanEnable） | 扫描数据进入、移出和模式选择所使用的端口或信号。 |
| lock-up latch | 锁存隔离单元（lock-up latch） | 用于跨时钟或跨边沿扫描移位时隔离时钟相位差的锁存器。 |
| Technology Mapping | 目标库实现（Technology Mapping） | 将逻辑结构选择为目标工艺库单元的综合阶段。 |

## ATPG 与覆盖率

| 英文术语 | 规范中文名称 | 说明 |
| --- | --- | --- |
| ATPG | 自动测试向量生成（Automatic Test Pattern Generation） | 针对故障模型生成测试激励和期望响应。 |
| Fault Coverage | 故障覆盖率（Fault Coverage） | 已检测故障占目标故障集合的比例。 |
| Test Coverage | 测试覆盖率（Test Coverage） | 工具采用的测试覆盖率指标；应查看报告中对不可检测与不可测故障的处理方式。 |
| coverage estimate | 覆盖率估算（coverage estimate） | 基于当前 DFTC 模型得到的估算值，不等同于 ATPG 工具对完整网表生成向量后的结果。 |
| fast sequential ATPG | fast sequential ATPG | 处理跨多个捕获周期状态关系的 ATPG 模式；保留工具原文。 |
| Test Point | 测试点（Test Point） | 为增强可控性或可观测性而加入的测试逻辑位置。 |
