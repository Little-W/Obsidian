## 一、RVV指令内容

RISC-V 向量扩展（RVV）包含多个指令，涉及向量计算、加载、存储、掩码操作、配置设置等功能。

### 1. 向量配置指令（Configuration Instructions）

#### 1.1 `vsetvli` 指令

`vsetvli`（Set Vector Length and Type Instruction）用于设置向量长度（VL）和向量类型（vtype）。它可以动态地配置向量长度，并在执行向量指令之前设置适当的配置。

**格式**：

```assembly
vsetvli rd, rs1, vtype
```

- `rd`: 用于存储返回的 `VL` 值（向量长度）。
    
- `rs1`: 存储 AVL（向量长度值）。
    
- `vtype`: 设置向量类型的配置。
    

**功能**：  
该指令根据输入参数，设置向量长度和类型，并将结果存储到 `rd` 寄存器中。它在程序中用于控制向量操作的粒度，确保向量指令按正确的向量长度执行。

#### 1.2 `vsetivli` 指令

`vsetivli`（Set Immediate Vector Length and Type Instruction）与 `vsetvli` 类似，但是它接受一个立即数值作为 AVL（向量长度）。

**格式**：

```assembly
vsetivli rd, uimm, vtype
```

- `rd`: 存储返回的 `VL` 值（向量长度）。
    
- `uimm`: 存储立即数 AVL。
    
- `vtype`: 设置向量类型的配置。
    

**功能**：  
这条指令通过给定的立即数设置向量长度和类型，适用于已知向量长度的情况。

#### 1.3 `vsetvl` 指令

`vsetvl`（Set Vector Length）用于直接设置 `VL` 寄存器的值，而不通过其他寄存器传递。

**格式**：

```assembly
vsetvl rd, rs1, rs2
```

- `rd`: 存储返回的 `VL` 值（向量长度）。
    
- `rs1`: 输入 AVL 值。
    
- `rs2`: 输入 vtype 值。
    

**功能**：  
`vsetvl` 直接将 `VL` 设置为由 `rs1` 和 `rs2` 定义的值。

### 2. 向量加载与存储指令（Vector Load/Store Instructions）

#### 2.1 向量加载指令

向量加载指令用于将数据从内存加载到向量寄存器中。

**格式**：

```assembly
vld v1, (a0)
```

- `v1`: 目标向量寄存器。
    
- `(a0)`: 内存地址。
    

**功能**：  
从地址 `a0` 中加载数据到向量寄存器 `v1`。

#### 2.2 向量存储指令

向量存储指令将向量寄存器的数据存储到内存中。

**格式**：

```assembly
vst v1, (a0)
```

- `v1`: 源向量寄存器。
    
- `(a0)`: 目标内存地址。
    

**功能**：  
将寄存器 `v1` 中的数据存储到内存地址 `a0` 中。

---

### 3. 向量算术指令（Vector Arithmetic Instructions）

#### 3.1 向量加法指令

向量加法指令用于将两个向量元素按元素地相加。

**格式**：

```assembly
vadd v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素按位相加，结果存储到 `v1` 中。

#### 3.2 向量减法指令

向量减法指令用于将两个向量元素按元素地相减。

**格式**：

```assembly
vsub v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素按位相减，结果存储到 `v1` 中。

#### 3.3 向量乘法指令

向量乘法指令用于将两个向量元素按元素地相乘。

**格式**：

```assembly
vmul v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素按位相乘，结果存储到 `v1` 中。

#### 3.4 向量除法指令

向量除法指令用于将两个向量元素按元素地相除。

**格式**：

```assembly
vdiv v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 中的元素除以 `v3` 中的元素，结果存储到 `v1` 中。

---

### 4. 向量比较指令（Vector Comparison Instructions）

#### 4.1 向量相等比较指令

向量相等比较指令用于按元素比较两个向量是否相等。

**格式**：

```assembly
veq v1, v2, v3
```

- `v1`: 结果向量寄存器，包含比较结果。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素逐个比较，若相等则设置 `v1` 中相应位置为 1，否则为 0。

#### 4.2 向量大于比较指令

向量大于比较指令用于按元素比较两个向量的大小。

**格式**：

```assembly
vgt v1, v2, v3
```

- `v1`: 结果向量寄存器，包含比较结果。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素逐个比较，若 `v2[i] > v3[i]`，则将 `v1[i]` 设置为 1，否则为 0。

---

### 5. 向量掩码操作指令（Vector Masking Instructions）

#### 5.1 向量掩码与操作指令

向量掩码与操作指令用于根据掩码条件控制向量元素的计算。

**格式**：

```assembly
vmask v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
根据掩码寄存器的值，决定是否执行 `v2` 和 `v3` 的操作，将结果存储在 `v1` 中。

#### 5.2 向量掩码或操作指令

向量掩码或操作指令用于按掩码条件对向量进行或操作。

**格式**：

```assembly
vor v1, v2, v3
```

- `v1`: 结果向量寄存器。
    
- `v2`, `v3`: 操作数向量寄存器。
    

**功能**：  
将 `v2` 和 `v3` 中的元素按位进行或运算，结果存储到 `v1` 中。

---

### 6. 向量归约操作指令（Vector Reduction Instructions）

#### 6.1 向量加法归约指令

向量加法归约指令用于将向量中的所有元素相加，得到一个标量结果。

**格式**：

```assembly
vredsum v1, v2
```

- `v1`: 结果寄存器，存储最终的加和结果。
    
- `v2`: 操作数向量寄存器。
    

**功能**：  
对 `v2` 中的所有元素执行加法归约操作，并将结果存储到 `v1` 中。

#### 6.2 向量最小归约指令

向量最小归约指令用于将向量中的所有元素进行最小值归约。

**格式**：

```assembly
vredmin v1, v2
```

- `v1`: 结果寄存器，存储最小值。
    
- `v2`: 操作数向量寄存器。
    

**功能**：  
对 `v2` 中的所有元素执行最小值归约操作，并将结果存储到 `v1` 中。

#### 7.2 向量按位或操作指令

向量按位或操作指令用于将两个向量进行按位或运算。

**格式**：

```assembly
vor v1, v2, v3
```

- `v1`: 结果向量寄存器。

将 `v2` 和 `v3` 中的元素按位或运算，结果存储到 `v1` 中。
