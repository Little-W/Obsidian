# SmarTest 8 时序、波形与数字比较

本章建立 period、edge、waveform、vector 和 strobe 的关系。完成后，读者应能从 DUT AC 规格编写 timing 工作表，解释为什么“pattern 正确”仍可能发生 timing fail。

## 1. 四个时间概念

| 概念 | 含义 | 常见错误 |
| --- | --- | --- |
| Device cycle | DUT 协议中的一个逻辑周期 | 与 tester 内部执行周期混为一谈 |
| Tester cycle | ATE sequencer 执行一个基本周期 | 忽略 X-mode 后的倍数关系 |
| Edge | driver 改变或 comparator 采样的时刻 | 只设 period，不检查 edge |
| Strobe | comparator 读取 DUT 输出的时刻或时间窗 | 放在 DUT 输出尚未稳定的位置 |

一个 vector 并不只是 `0/1/H/L` 字符。字符要引用 waveform，waveform 再定义该周期内何时驱动、何时切换方向、何时比较。

## 2. 从 AC 规格建立 Timing 工作表

以同步计数器为例：

| 项目 | DUT 规格字段 | Timing 设置要表达什么 |
| --- | --- | --- |
| 时钟周期 | `tCK` 或 `fMAX` | period |
| 高/低脉宽 | `tWH/tWL` | drive edges |
| 输入建立/保持 | `tSU/tH` | 数据相对有效时钟沿的位置 |
| 时钟到输出 | `tCO` | strobe 最早位置 |
| 输出有效保持 | `tVALID` | compare window |
| 复位脉宽 | `tRST` | pattern 周期数与复位 waveform |

如果 `f = 10 MHz`，理想 period 为：

```text
T = 1 / f = 100 ns
```

这只确定周期长度。还要决定 `CLK` 在周期内何时上升/下降，输入在有效沿之前多久稳定，输出在何时比较。

## 3. 驱动波形

常见数字波形概念包括：

| 类型 | 行为 | 适用说明 |
| --- | --- | --- |
| NRZ | 状态在周期内保持，必要时在边沿改变 | 一般数据输入 |
| RZ | 周期中驱动有效电平，随后返回基准状态 | 脉冲或时钟类信号 |
| RO | 与 RZ 相反的返回行为 | 取决于协议和工具模板 |
| Hi-Z / turnaround | driver 断开，等待 DUT 接管 | 双向总线方向切换 |

工具中的具体 waveform 名称和字符由当前 wavetable 决定。不要假定 `1` 在所有项目中都表示完全相同的 edge 组合。

## 4. 比较波形与 Strobe

Comparator 可能执行单点 strobe、窗口比较或其他板卡支持的模式。strobe 应落在 DUT 输出已经越过 `VOL/VOH` 门限并保持稳定的区域。

选择 strobe 时依次考虑：

1. DUT 的 clock-to-output 最大时间；
2. DUT board 的传播延迟和 site 差异；
3. tester driver/comparator 及校准误差；
4. 接口的反射、过冲和建立过程；
5. 量产 guardband 与相关性数据。

只在 nominal 样品上把 strobe 移到 pass 区中心，不能代替跨电压、温度、site 和批次的评估。

## 5. X-Mode 与 Data Rate

PS1600 公开资料给出最高 1600 Mbps data rate 和 400 MHz base rate。较高 data rate 可通过一个 tester cycle 内的多次数据操作实现。`X4` 例子中，一个 2.5 ns base cycle 可表达四个数据单元，因此数据间隔可达到 625 ps；具体 pattern 组织、许可和模式以当前 TDC 为准。

区分以下量：

```text
base rate ≠ data rate ≠ DUT clock frequency
```

例如 DDR 数据在一个时钟周期的两个边沿传输，data rate 可以是 clock frequency 的两倍。不能仅看 DUT 时钟频率就判断 PS1600 是否满足速度要求。

## 6. 一个最小 Timing 例子

以下数值仅用于说明计算，不代表真实 DUT 条件：

| 参数 | 教学值 | 作用 |
| --- | ---: | --- |
| Period | 100 ns | 10 MHz device cycle |
| `CLK` rising edge | 25 ns | DUT 有效时钟沿 |
| `CLK` falling edge | 75 ns | 50% 高电平时间 |
| 输入数据变化 | 0 ns | 在有效沿前 25 ns 稳定 |
| 输出 strobe | 60 ns | 在有效沿后 35 ns 比较 |

若 DUT 要求 `tCO(max)=20 ns`，strobe 60 ns 相对 25 ns 有效沿晚 35 ns，理论上留出 15 ns 余量。还需扣除板级传播、tester 精度和 guardband 才能决定是否合适。

## 7. Timing Debug 顺序

1. 固定 level、pattern 和 DUT 温度。
2. 在低频条件确认基本功能。
3. 查看 first fail cycle 和失败信号。
4. 展开该周期实际 waveform 和 edge。
5. 检查 period 与 specification 变量是否解析正确。
6. 只移动一个参数，例如 strobe 或输入 edge。
7. 记录 pass/fail 变化，再做二维 Shmoo。
8. 若多个 site 差异明显，检查硬件路径和接触。

## 8. 常见失败

| 现象 | 可能原因 | 检查 | 处理 |
| --- | --- | --- | --- |
| 低频通过，高频固定周期失败 | strobe 太早、输入建立不足 | first fail 与 Timing Debug | 调整受控时序或修正 DUT 接口 |
| 所有向量从第一个周期失败 | clock 极性、waveform 字符或复位错误 | 查看首周期驱动与 compare | 修正 wavetable/pattern 关系 |
| 每个 site 的最佳 strobe 不同 | 路径长度、接触或 site 资源差异 | per-site Shmoo 与物理检查 | 修复接口，不用过宽窗口掩盖 |
| X-mode pattern 无法绑定 | vector 数、模式或内存条件不满足 | 查看 binding report | 按当前模式重新转换 pattern |
| 双向总线在切换点大电流 | tester 与 DUT 同时驱动 | 查看 turnaround waveform | 增加批准的 Hi-Z 时间 |

## 9. 练习

> [!question] Strobe 计算
> 有效时钟沿位于 10 ns，DUT 的 `tCO(max)` 为 12 ns，板级和 tester 的总预留为 4 ns。strobe 最早应放在什么位置之后？

> [!note]- 参考答案
> 最早位置为 `10 ns + 12 ns + 4 ns = 26 ns` 之后。还要确保该位置没有越过下一次输出变化，并依据产品测试策略加入必要的 guardband。
