# SmarTest 8 电平配置与保护策略

本章说明数字 driver、comparator、clamp、终端和每引脚 PMU 的电平设置。完成后，读者应能从 DUT 数据手册推导保守的 level setup，并能检查设置是否同时落在 DUT 和 PS1600 的允许范围内。

## 1. 两组容易混淆的参数

ATE 数字测试至少同时处理两组电压：

| 对象 | 常见名称 | 表示什么 | 依据 |
| --- | --- | --- | --- |
| Tester 驱动 DUT | `VIL`、`VIH` | 测试机发送逻辑 0/1 时的实际电平 | DUT 输入条件与 tester driver 能力 |
| Tester 判断 DUT | `VOL`、`VOH` | 测试机把 DUT 输出判断为低/高的门限 | DUT 输出规格与 tester comparator 能力 |

名字相似不代表数值相同。若 DUT 规定输入高电平至少 1.2 V，tester 的 `VIH` 应在允许范围内高于该值；若 DUT 规定输出高电平至少 1.4 V，tester 的 `VOH` 门限应按测试目的设在该规格附近，而不是自动等于 driver 的 `VIH`。

## 2. 从数据手册提取 Level 条件

建立一张条件表：

| 字段 | 数据手册来源 | 示例占位值 | 说明 |
| --- | --- | --- | --- |
| `VDD_MIN/NOM/MAX` | Recommended Operating Conditions | `<... V>` | 电源域 |
| `VIL_MAX_DUT` | DC Input Characteristics | `<... V>` | DUT 必须识别为低的最高输入 |
| `VIH_MIN_DUT` | DC Input Characteristics | `<... V>` | DUT 必须识别为高的最低输入 |
| `VOL_MAX_DUT` | DC Output Characteristics | `<... V @ ... mA>` | 指定输出电流条件 |
| `VOH_MIN_DUT` | DC Output Characteristics | `<... V @ ... mA>` | 指定输出电流条件 |
| `ABS_PIN_MIN/MAX` | Absolute Maximum Ratings | `<... V>` | 不得达到或越过 |
| `IOH/IOL` | DC Output Characteristics | `<... mA>` | 与输出门限测试条件相关 |

> [!important] 输出电平规格通常带电流条件
> `VOH` 和 `VOL` 常在指定 `IOH/IOL` 下成立。若只用高阻 comparator 做功能比较，得到的是电压逻辑结果；若要验证规定输出电流能力，需要使用批准的有源电流设置或参数测量方法。

## 3. 设置步骤

### 3.1 Driver Level

1. 确定信号所属电源域。
2. 从 DUT 规格读取 `VIL_MAX_DUT` 和 `VIH_MIN_DUT`。
3. 选择不会接近绝对最大值的 `VIL_TEST` 与 `VIH_TEST`。
4. 检查所选值是否落在板卡 driver 范围内。
5. 检查 DUT 未上电时的允许输入状态。
6. 为 nominal、low-voltage 和 high-voltage 条件建立规格变量，不复制多份散落数值。

基本条件为：

```text
ABS_PIN_MIN < VIL_TEST <= VIL_MAX_DUT
VIH_MIN_DUT <= VIH_TEST < ABS_PIN_MAX
```

这个不等式只表达静态合法性，还要考虑噪声、过冲、板卡精度和 DUT board 压降。

### 3.2 Comparator Level

若目标是严格按器件规格判断：

```text
VOL_TEST = DUT 规定的 VOL 最大值
VOH_TEST = DUT 规定的 VOH 最小值
```

实际项目可能根据 guardband、相关性和质量目标使用经批准的偏移值。任何偏移都应记录原因和统计依据，不能为了“让测试通过”临时放宽。

### 3.3 Clamp 与终端

Clamp 用于限制异常电压，终端和 driver 输出阻抗影响反射与幅度。配置时确认：

- clamp 电压不会在正常波形上导通；
- clamp 能保护 tester 和 DUT，但不替代 DUT 绝对最大值控制；
- 50 Ω 前端与 DUT board 端接方案一致；
- 双向 I/O 在 turnaround 期间有明确 Hi-Z 时间；
- 外部上拉/下拉和 tester 有源电流设置不会相互对抗。

## 4. 规格变量的组织

推荐把物理含义写进变量名：

```text
VDDIO_NOM
VDDIO_MIN
VDDIO_MAX
CLK_VIL
CLK_VIH
DATA_VOL_LIMIT
DATA_VOH_LIMIT
```

不要使用 `v1`、`v2`、`high` 之类缺少对象的名称。多个电源域必须分开，例如 `VDD_CORE_NOM` 与 `VDD_IO_NOM`。

## 5. 三类 Level Setup

| Setup | 用途 | 变化内容 | 不应改变的内容 |
| --- | --- | --- | --- |
| `lvl_nominal` | 基本功能测试 | 额定 VDD 对应 driver/comparator | signal 方向和 pin 关系 |
| `lvl_vdd_min` | 低电压功能或 characterization | VDD 和经批准的门限 | DUT 绝对最大值 |
| `lvl_vdd_max` | 高电压功能或 characterization | VDD 和经批准的门限 | 保护与电流限制 |

若 DUT I/O 门限按 VDD 比例变化，应通过规格变量表达关系，并检查工具支持的表达方式。不要只改 DPS 电压而保留不适用的 comparator 门限。

## 6. PS1600 范围检查

一份 2025 年 V93000 PS1600/CTH 计量注册资料给出下列范围：常规 driver 与 comparator 为 −1.5 V 至 +6.5 V，driver 电压分辨率 1 mV；每 16 个引脚中的专用宽范围 driver 可覆盖 `VIL/VIH` 0 V 至 6.5 V 和 `VHH` 6 V 至 13.4 V。该数值只适用于资料所述系统配置，详见 [[12-PS1600硬件参数与配置]]。[V93000 PS1600/CTH 计量资料](https://all-pribors.ru/docs/2025-96652-25.pdf)

范围检查采用双重限制：

```text
合法设置 = DUT 允许范围 ∩ 当前板卡/通道/模式允许范围
```

宽范围 driver 不是每个通道都有。若 pin plan 把高压信号放到普通通道，即使软件变量数值合理，硬件资源仍不满足。

## 7. 最小离线实验

### 7.1 输入

- 计数器示例 pin 配置；
- 假定的 1.8 V DUT level 条件表；
- 当前 SmarTest 8 版本批准的 level setup 模板。

### 7.2 操作

1. 建立 `VDDIO_NOM`、`CLK_VIL`、`CLK_VIH`、`Q_VOL_LIMIT` 和 `Q_VOH_LIMIT`。
2. 给 `CLK/RST_N/EN` 绑定 driver level。
3. 给 `Q[7:0]` 绑定 comparator level。
4. 将所有非驱动状态设为批准的 Hi-Z 行为。
5. 在 Instrument View 或等效离线视图中检查解析后的值。
6. 对照 DUT 与 PS1600 范围表逐项复核。

### 7.3 预期结果与通过条件

- 所有变量有单位和所属电源域；
- driver 与 comparator 参数没有互换；
- 解析后的值同时满足 DUT 和板卡限制；
- 工具不报告未定义规格变量；
- 该结果仅记录为“离线配置检查完成”。

## 8. 常见失败

| 现象 | 可能原因 | 检查 | 处理 |
| --- | --- | --- | --- |
| 所有输出始终 fail high | `VOH` 过高、输出未使能或 pin 方向错误 | 查看 comparator 值和方向 | 恢复规格门限，检查 pattern |
| 输出波形有明显过冲 | 端接、路径阻抗或 edge rate 不合适 | 在批准测点观察波形 | 调整硬件或受控 slew 设置 |
| 未上电时 DUT 电流异常 | 数字 pin 反向供电 | 检查 power-off 初态 | 上电前保持 Hi-Z 或批准低电平 |
| 高压信号配置被拒绝 | 通道没有宽范围 driver | 查 pogo/channel 资源 | 改用具备资源的通道 |
| 低电压 Shmoo 结果异常 | comparator 门限未随电源条件调整 | 展开实际 level 值 | 使用条件化规格变量 |

## 9. 本章检查

- [ ] driver 与 comparator 参数分开设置；
- [ ] 每个 level 数值能追溯到 DUT 规格或批准的 guardband；
- [ ] DUT 允许范围与板卡范围取交集；
- [ ] power-off 初态和双向 turnaround 已定义；
- [ ] 宽范围 driver 的物理通道已经确认。
