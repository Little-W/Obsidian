# V93000 DPS128 与供电资源配置

本章说明 DC Scale DPS128 的电压、电流和并联通道配置，并给出 DUT 电源预算方法。数值来自 [[参考资料/公开参数资料/V93000_PS1600_CTH_计量注册_96652-25_2025.pdf|2025 年公开计量注册资料]]中所列的一套 V93000 配置，不代表所有 DPS128 版本。

## 1. DPS 与数字 pin 的分工

| 资源 | 主要用途 | 不适合替代的用途 |
| --- | --- | --- |
| DPS128 | DUT 电源、静态/动态电流、上电顺序 | 高速数字波形 |
| PS1600 driver/comparator | 数字激励与比较 | DUT 主电源 |
| PS1600 PPMU | 单 pin 参数测量 | 多电源域的大电流持续供电 |
| HPPMU | 更精细的参数测量 | 普通高速功能测试 |

## 2. 公开参数

### 2.1 电压

| 项目 | 范围/指标 |
| --- | --- |
| 输出电压范围 | −2.5 V～+7 V |
| 设置分辨率 | 200 µV |
| Force V 绝对误差 | ±3 mV |
| Measure V 绝对误差 | ±2 mV |

### 2.2 每通道电流

| 输出电压 | 公开资料所列最大电流 |
| --- | ---: |
| −2.5 V～+2.5 V | 1 A/channel |
| >2.5 V～+7 V | 0.5 A/channel |

### 2.3 电流量程

公开资料列出的量程为：

```text
12.5 µA, 25 µA, 125 µA, 250 µA,
1.25 mA, 2.5 mA, 12.5 mA, 25 mA,
100 mA, 200 mA, 1 A
```

资料还列出通道并联时理论上限可到 `n × 1 A`。实际可用值还受电压区间、板卡功率、机架供电、散热、DUT board 铜阻、pogo 和连接器限制，不能只按通道数相乘。

### 2.5 电流准确度

下面把 2025 公开计量资料中的公式整理为便于查阅的表。`I` 以 µA 代入。

| 量程 | Force I 绝对误差 | Measure I 绝对误差 |
| ---: | --- | --- |
| 12.5 µA | ±(0.002I + 0.12 µA) | ±(0.002I + 0.05 µA) |
| 25 µA | ±(0.002I + 0.12 µA) | ±(0.002I + 0.05 µA) |
| 125 µA | ±(0.002I + 0.75 µA) | ±(0.001I + 0.25 µA) |
| 250 µA | ±(0.002I + 0.75 µA) | ±(0.001I + 0.25 µA) |
| 1.25 mA | ±(0.002I + 7.5 µA) | ±(0.001I + 2.5 µA) |
| 2.5 mA | ±(0.002I + 7.5 µA) | ±(0.001I + 2.5 µA) |
| 12.5 mA | ±(0.002I + 75 µA) | ±(0.001I + 25 µA) |
| 25 mA | ±(0.002I + 75 µA) | ±(0.001I + 25 µA) |
| 100 mA | ±(0.002I + 600 µA) | ±(0.001I + 250 µA) |
| 200 mA | ±(0.002I + 600 µA) | ±(0.001I + 250 µA) |
| 1 A | ±(0.002I + 3000 µA) | ±(0.001I + 1000 µA) |

Force I 公式只适用于资料为各量程注明的有效区间，通常是该量程的 20%～100%；接近零点或跨量程时要查原表。并联 `n` 通道时，资料给出的高电流区 Force I 误差为 `±(0.002I + n×3 mA)`，Measure I 误差为 `±(0.001I + n×1 mA)`，这里的 `I` 以 mA 代入。

## 3. 电源预算

为每个电源域建立下表：

| 字段 | 示例 | 来源 |
| --- | ---: | --- |
| `V_MIN/NOM/MAX` | 1.71/1.80/1.89 V | DUT 推荐工作条件 |
| `I_STATIC_MAX` | 80 mA | DUT DC 规格 |
| `I_DYNAMIC_EST` | 350 mA | 设计估算或板上测量 |
| `I_INRUSH` | 700 mA | 上电实测或规格 |
| `I_LIMIT_START` | 450 mA | 初次调试保护值 |
| 通道数 | 1 或更多 | tester 资源表 |
| 路径压降 | 30 mV | DUT board 评估 |

电流限制应高于正常峰值并低于可能损坏 DUT、socket、走线或 tester 的水平。初次调试从较低、能观察的设置开始，确认波形后再按批准方案调整。

## 4. Kelvin 与远端感测

若板卡和 DUT board 支持 sense，Force 线提供电流，Sense 线读取 DUT 附近电压。必须确认：

- Sense+ 与 Sense− 接到批准测点；
- sense 线断开时系统的保护行为；
- 多 site 不会把不同 DUT 的 sense 接在一起；
- 远端感测补偿不会使源端电压越过 DUT board 或通道限制；
- 上电前完成 continuity 和接触检查。

## 5. 上电与下电顺序

一个通用教学顺序如下，真实器件必须服从数据手册：

```mermaid
flowchart LR
    A[数字 pin 为安全状态] --> B[检查接触]
    B --> C[设置电流保护]
    C --> D[使能第一电源域]
    D --> E[确认电压与电流]
    E --> F[使能其余电源域]
    F --> G[释放复位并运行测试]
    G --> H[恢复数字 pin 安全状态]
    H --> I[按规定次序关闭电源]
```

每使能一个电源域后，都检查实际电压和电流，再继续下一步。异常退出和用户 abort 也必须执行安全下电。

## 6. 并联通道示例

假设 DUT 在 1.8 V 时需要 1.4 A。公开单通道能力为 1 A，因此概念上至少需要两个通道并联：

```text
所需通道数 >= ceil(1.4 A / 1 A) = 2
```

这只是第一步。还应检查：

- 两通道是否属于允许并联的资源；
- current sharing 和 sense 接法；
- DUT board 每条路径能承受的电流；
- 两通道合计功率与温升；
- 过流时两个通道是否按预期关闭。

## 7. 初次上电实验

### 输入

- 经过审阅的电源域表；
- 已确认的 DUT board 与 socket/probe card；
- 单 site、低风险样品；
- 电流保护和停止条件。

### 操作

1. 断开高速 pattern，所有数字 pin 处于批准安全状态；
2. 设置电压 0 V 或工具规定的关闭状态；
3. 设置保守电流保护；
4. 按小步或批准 ramp 上升到目标电压；
5. 每一步记录 Force V、Measure V 和电流；
6. 发现异常立即关闭，并保存记录；
7. 目标电压稳定后再释放复位。

### 通过条件

- DUT 端测量电压在批准容差内；
- 静态和瞬态电流没有触发保护；
- 各电源域顺序与时间满足 DUT 要求；
- 下电后所有电源和数字 pin 回到安全状态。

## 8. 常见失败

| 现象 | 可能原因 | 检查 | 处理 |
| --- | --- | --- | --- |
| 设置 1.8 V，DUT 端偏低 | 路径压降或 sense 接法错误 | 对比源端和 DUT 端 | 修复接线或启用批准的 sense |
| 上电立即过流 | DUT 方向、短路、顺序或电流限制错误 | 断电后做电阻和接触检查 | 不要反复强制上电 |
| 多 site 才过流 | 同时电流和功率不足 | 逐 site 增加并记录 | 重新规划资源和执行顺序 |
| 动态测试电压下陷 | 瞬态电流、路径电感或去耦不足 | 看 DUT 端波形 | 修正 DUT board 和电源设置 |

## 9. 本章检查

- [ ] 每个电源域有电压、电流、顺序和保护条件；
- [ ] 已区分 2.5 V 以下与较高电压区间的电流能力；
- [ ] 并联通道经过资源、布线、功率和异常测试；
- [ ] Sense 接法和断线行为已确认；
- [ ] 正常结束与异常退出都能安全下电。
