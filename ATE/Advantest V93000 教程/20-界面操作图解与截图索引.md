# V93000 界面操作图解与截图索引

本章集中说明 SmarTest 界面入口。SmarTest 7 不同修订版可能采用传统 Data Manager 或 Eclipse Workcenter 外观；SmarTest 8 也会随发行版和客户插件变化。操作时先按对象名称定位，再按当前 TDC 确认菜单文字。

## 3. 启动、Workspace 与 Device

公开计量文档中的传统启动流程是：

1. 启动 SmarTest；
2. 在 Workspace Launcher 选择 workspace；
3. 打开 Workcenter；
4. `93000 > Device > Change Device...`；
5. `Browse...` 后选择 device/project；
6. 观察 Console，确认 user、device、technology 和启动状态。

### 主窗口区域

| 区域 | 位置 | 用途 |
| --- | --- | --- |
| Test Program Explorer | 左侧 | Device Information、Testflow、Pin、Levels、Timing、Pattern 等对象 |
| 编辑区 | 中间 | 打开的 editor、flow 或 setup |

## 4. 打开、加载与运行 Testflow

### 4.1 传统 Data Manager：打开编辑器

历史原厂培训手册给出准确入口：

1. `Select > Program`；
2. 双击 `TESTFLOW` 图标；
3. 或点击主按钮区的 `Testflow`；
4. Testflow Editor 打开。

如果是新 flow，只看到 `START` 和插入点是正常现象。选择插入点，再用 `Insert > Run Test` 或 `Insert > Run and Branch` 添加 Test Suite。

### 4.2 传统 Data Manager：加载已有 flow

1. Program 页选择 `TESTFLOW` 图标；
2. `File > Load`；
3. 在 Testflow 文件列表选目标 flow；
4. 点击 `Load`；
5. 双击 `TESTFLOW` 图标打开 Testflow Editor；
6. `File > Load Setups`。

### 4.3 Eclipse Workcenter 形式

1. 在左侧 `Test Program Explorer` 展开当前 device；
2. 在 `Device Information` 下找到 `Testflow`；
3. 右键，选择 `Load...`；
4. 选目标文件并确认；
5. 再右键选择 `Load All Setups`，或进入编辑器执行 `File > Load Setups`；
6. 双击 Testflow 对象或按当前上下文菜单打开 editor；
7. 在 Console/Error Log 中检查首个错误。

![[界面与设备截图.assets/legacy-smt7-load-flow-page-10.png|850]]

*图 3：`Select file to load` 与 `Load Action` 窗口实例。来源：[[参考资料/公开参数资料/V93000_PS1600_legacy_metrology_2016.pdf|公开计量文档]]第 10 页；非 Advantest 官方截图。图中选的是计量程序文件，日常项目应选择自己的已批准 Testflow。*

### 4.4 加载顺序

历史原厂手册明确要求：

```text
Pin Configuration 最先
Timing setup 在 Vector setup 之前
```

`Load Testflow` 只加载 flow 内容，不等于 setup 已进入 tester。若 Test Suite 的 Select 对话框为空，先检查相关 setup 是否成功加载。

### 4.5 执行与中止

在 Testflow Editor 中：

- `File > Execute All`：执行完整 flow；
- 选中部分元素后 `File > Execute`：只执行所选部分；
- `File > Abort`：中止；
- Test Suite dialog 的 `Exec All & Stop Here`：从开头运行并停在当前 suite 后，适合逐步调试（若当前版本提供）。

Workcenter 形式也可能在 Testflow 对象右键菜单中提供 `Run`。运行前保存修改，确认 connect/disconnect 与 power-off 动作存在。

## 5. 打开 Level Eqnset 编辑器

历史 Level Setup Editor：

1. 从全局 Setup dialog 或 Test Suite dialog 选择 Level setup；
2. 点击 `Edit`，进入 Level Setup Editor；
3. `Select > Edit Equations`；
4. 在 Level Equation Editor 中编辑 `EQNSET`；
5. 点击右下角 `Download`；
6. 检查 Report/Error；
7. 回到 Level Setup Editor，`Select > Edit Specifications`；
8. 选 Eqnset，建立或编辑 Specset；
9. 保存 setup。

如果 Spec Tool 中没有变量，优先检查 Eqnset 是否已成功 Download，以及 `SPECS` 是否解析成功。

## 6. 打开 Timing Eqnset 与 Wavetable

典型入口：

1. 从 Setup dialog 或 Test Suite dialog 选 Timing setup 并 `Edit`；
2. Timing Setup 窗口中 `Select > Edit Equations`，打开 Timing Equation Editor；
3. 编辑 `EQNSET / SPECS / EQUATIONS / TIMINGSET / PINS`；
4. Download 并检查错误；
5. 打开 Wavetable 编辑器，核对 `d1/d2/d3/r1`；
6. 打开 Specifications，填写 Timing Specset；
7. 查看展开后的 period 和 edge；
8. 保存后再加载 Vector setup。

历史原厂培训手册第 9 章含 Timing Setup/Wavetable 界面图；在线入口见 [Agilent 93000 SOC Series User Training Part 1](https://vantwillert.net/training/93K%20Part%20I/part1_manual_4.2.1.pdf)。

## 7. 打开和编辑 Test Suite

1. 在 Testflow Editor 中双击 suite 图形；
2. 检查 `Timing Equation / Timing Spec Set / Timing Set`；
3. 点击相应字段后 `Select`，先选 Eqnset+Specset，再选该 Eqnset 内的 Timingset；
4. Level 三项采用相同步骤；
5. 在 `Vector Label` 字段点击 `Select`；
6. 选择 Test Function/Test Method；
7. 检查 suite 名称、limits、test number 和分支；
8. `Done`，保存 Testflow。

若 Select 列表为空，通常是相关 setup 未加载，而不是 Eqnset 一定不存在。

## 8. Report 与 Error Log

![[界面与设备截图.assets/legacy-smt7-report-page-12.png|850]]

*图 4：`ui_report` 中的执行结果实例。来源：[[参考资料/公开参数资料/V93000_PS1600_legacy_metrology_2016.pdf|公开计量文档]]第 12 页；非 Advantest 官方截图。*

阅读顺序：

1. 确认 device、testflow 和仪器/硬件标识；
2. 从第一条 warning/error 开始，不先看最后一条连带错误；
3. 记录 suite、channel/site、实际值、limit 和 pass/fail；
4. 若失败来自外部连接提示，先确认连接再继续；
5. 保存原始 Report，不只截取最终 pass 行。

## 9. Help 与 TDC

- SmarTest 中使用 `Help > Help Contents`；
- 按当前软件发行版搜索对象名，例如 `Level Equation Editor`、`Timing Equation Editor`、`Testflow Editor`；
- 板卡字段按准确型号搜索，例如 `Pin Scale 1600` 或 `DPS128`；
- 若本地 Help 不含目标内容，使用 myAdvantest/TDC，并记录文档版本。

Advantest 官方说明指出，V93000 的完整技术文档和下载需要相应客户权限。[V93000 Technical Documentation](https://www3.advantest.com/service-support/ic-test-systems/products-list/v93000-technical-documentation/)

## 10. UI 故障速查

| 现象 | 优先检查 |
| --- | --- |
| 左侧没有当前 device | Workspace、Change Device、project import |
| 双击 Testflow 没有内容 | 是否先 Load；是否打开了正确 device |
| 只有 START | 这是新 flow；需要插入 Test Suite |
| Test Suite 的 Select 为空 | 对应 setup 尚未加载 |
| Load All Setups 连续报错 | 找第一条错误；先 Pin，再 Timing，再 Vector |
| 修改后运行仍是旧值 | setup/Testflow 是否 Save；运行进程是否重新加载旧文件 |
| Report 无数值 | Test Method 是否提交结果，datalog 模式是否启用 |
| 窗口名称与本章不同 | 软件修订版不同；用对象名在本机 Help 搜索 |
