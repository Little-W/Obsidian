# V93000 术语速查与资料索引

## 1. 核心术语

| 术语 | 本课程中的含义 |
| --- | --- |
| V93000 / 93K | Advantest SoC 测试平台；93K 是常用简称 |
| SmarTest 7 | 传统 SmarTest 软件世代，本课程的 Eqnset 代码以其公开培训资料为依据 |
| SmarTest 8 | 当前官方产品页所述的 Linux、Eclipse、Java 软件环境 |
| Eqnset | Equation Set 的软件对象；以 `EQNSET` 开始，可包含规格声明、公式和 set |
| Specset | 给 `SPECS` 中变量提供实际值及可选 min/max 的规格集合 |
| Levelset | 一个 Level Eqnset 内的一组 driver/comparator/DPS 设置 |
| Timingset | 一个 Timing Eqnset 内的一组 period 和 edge 设置 |
| Wavetable | 把 pattern 字符与 driver/comparator 动作关联起来的波形表 |
| Pattern | 按 cycle 排列的输入、输出预期和 sequencer 控制 |
| Test Suite | 一项测试的 setup、method/function、pattern 和结果配置 |
| Testflow | Test Suite 的执行顺序、条件、循环、分档和异常动作 |
| PS1600 | Pin Scale 1600 通用数字板卡 |
| PPMU | Per-Pin Parametric Measurement Unit，每引脚参数测量单元 |
| HPPMU | High-Precision PMU，高精度参数测量单元 |
| DPS128 | 128 通道器件电源板卡族 |
| TDC | Technical Documentation Center，机台当前版本的正式文档入口 |
| Datalog | 测试结果、数值、单位、限值和设备条件记录 |
| Shmoo | 同时改变两项参数并绘制 pass/fail 区域 |
| Margin | 搜索某项参数的通过到失败转折位置 |

## 5. 获取正式官方手册

在有客户权限的环境中：

1. 在 SmarTest 中打开 `Help > Help Contents`；
2. 进入 TDC，按当前软件版本、板卡和主题搜索；
3. 如需下载软件与受限手册，登录 myAdvantest 并申请相应服务权限；
4. 把实际使用的手册版本号记录在项目说明中。

本课程不绕过登录或服务协议，也不把旧公开培训材料当作当前版本规格。
