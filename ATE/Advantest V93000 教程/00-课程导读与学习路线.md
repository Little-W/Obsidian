# Advantest V93000 教程：课程导读与学习路线

本课程面向第一次接触 Advantest V93000 的数字测试、产品测试、DFT 和失效分析工程师。读者完成全部章节后，应能解释 V93000 测试单元的组成，读懂 SmarTest 7 的 Eqnset/Testflow 与 SmarTest 8 的 Setup/Test Method 主要对象，制定数字功能测试和 DC 测试的配置表，并在有权限的离线环境或真实机台上按受控步骤完成首次调试。

> [!important] 本课程的证据范围
> 本课程根据 Advantest 公开产品页、官方培训议程、历史原厂培训资料的公开镜像、公开论文和可公开取得的计量资料编写。当前 SmarTest 7/8 的完整手册、API、板卡维修资料与正式实验工程需要 `myAdvantest` 权限或客户培训资格。本文中的操作框架没有在本机 V93000 上执行；任何电气值都必须以 DUT 数据手册、机台当前校准状态、已安装板卡版本和本单位批准的测试规范为准。

## 1. 先纠正三个常见名称

| 常见写法 | 本课程采用的写法 | 说明 |
| --- | --- | --- |
| adavan、advan | Advantest | 厂商名称 |
| 93K、93k | V93000 | 93K 是行业简称，正式产品族名称是 V93000 |
| Smartest、SmartTest | SmarTest | Advantest 软件名称；概念以当前 SmarTest 8 为主，Eqnset/Testflow 代码单列 SmarTest 7 路线 |
| eqn（口头简称） | Eqnset | 实际对象名为 Equation Set，代码入口为 `EQNSET` |

`PS1600` 是 Pin Scale 1600 通用数字板卡。它具有数字驱动、比较、每引脚 PMU 和有源电流单元等能力，但它不是 DUT 主电源板。`DPS128` 才是常见的高密度器件电源资源。二者的区别将在 [[12-PS1600硬件参数与配置]] 和 [[13-DPS128与供电资源配置]] 中展开。

## 2. 学习前提

读者应先具备以下知识：

- 会使用 Linux 文件系统和 Eclipse 类 IDE；
- 理解电压、电流、电阻、二极管、上升沿和下降沿；
- 理解数字输入、数字输出、双向 I/O、三态和时钟周期；
- 能阅读 DUT 数据手册中的 Absolute Maximum Ratings、Recommended Operating Conditions 和 DC/AC Characteristics；
- 若要编写 SmarTest 7 UTM Test Method，应具备项目所需的 C/C++ 基础；
- 若要编写 SmarTest 8 Test Method，应具备 Java 基础。

Advantest 官方基础培训也把半导体器件测试、Linux 和 Java 列为主要前提，并把 pin configuration、levels、timing、vectors、test suites、test flow、DC test、datalog、Shmoo 和 Margin 列为核心内容。[V93000 SmarTest 8 Basic User Training](https://www.advantest.com/en/customer-services/customer-training/onsite-training-na/application-training/v93000-st8-digital-user/)

## 3. 全课程使用的示例 DUT

为了让各章能够连贯阅读，课程使用一个假想的 1.8 V、8 位同步计数器作为统一例子。它不是某个真实器件，也没有在 V93000 上运行。

| 信号 | 方向 | 示例作用 | 实际项目必须替换的内容 |
| --- | --- | --- | --- |
| `VDD` | 电源 | 核心供电 | 额定电压、容差、最大电流、上电斜率 |
| `VSS` | 地 | 电气参考 | 接地与 Kelvin 连接方案 |
| `CLK` | 输入 | 上升沿计数 | 频率、占空比、抖动要求 |
| `RST_N` | 输入 | 低有效复位 | 复位时长、释放条件 |
| `EN` | 输入 | 高电平允许计数 | 输入门限和建立时间 |
| `Q[7:0]` | 输出 | 输出计数值 | 输出门限、有效时间窗 |

示例默认执行顺序如下：

```mermaid
flowchart LR
    A[安全初态] --> B[接触检查]
    B --> C[上电]
    C --> D[漏电与静态电流]
    D --> E[复位功能测试]
    E --> F[计数功能测试]
    F --> G[数据记录与分档]
    G --> H[安全下电]
```

每一步都必须回答五个问题：输入是什么、配置什么资源、产生什么结果、怎样确认结果、失败时先检查什么。

## 5. 如何使用离线环境与真实机台

### 5.1 离线环境能够确认什么

离线环境适合检查：

- 项目和测试程序文件能否被工具识别；
- 信号、信号组、规格变量和测试对象的引用是否一致；
- Testflow 是否存在不可达分支或明显的分档错误；
- Test Method 是否能够编译；
- pattern、timing 和 level 的绑定是否报告配置错误。

离线环境不能证明 DUT 得到了设定电压，不能证明继电器已经闭合，也不能证明测量精度和接触状态满足要求。公开论文同样强调，offline verification 不会施加或测量真实电气量。[Test Solution Development for Automated Test Equipment](https://ieeexplore.ieee.org/document/9009848)

### 5.2 在线机台开始前的最低条件

- 已确认 tester class、板卡型号、板卡修订版、许可证和校准有效期；
- 已由设备负责人批准 DUT board、socket/probe card 和外部仪器连接；
- 已从 DUT 数据手册提取绝对最大值和推荐工作条件；
- 已设置电压、电流、时间和功率保护；
- 第一次运行采用单 site、低风险电平、短 pattern 和受控停止点；
- 上电与下电序列均已审阅。

## 6. 完成条件

读者若能完成下面的检查，就达到了本课程的入门目标：

- [ ] 能说明 PS1600 与 DPS128 的分工；
- [ ] 能打开 Testflow Editor，并区分 Load Testflow 与 Load Setups；
- [ ] 能说明 Pin Configuration 先下载、Timing 先于 Vector 的顺序；
- [ ] 能解释 Eqnset、Specset 与 Levelset/Timingset 的关系；
- [ ] 能画出 DUT 信号到 tester channel 的对应表；
- [ ] 能从 DUT 数据手册推导 `VIL`、`VIH`、`VOL`、`VOH` 的保守设置；
- [ ] 能说明 device cycle、tester cycle、waveform 和 vector 的关系；
- [ ] 能解释 Test Method、Test Suite 与 Testflow 各自负责什么；
- [ ] 能制定 continuity、leakage、IDD 和 functional test 的安全顺序；
- [ ] 能区分离线检查、在线测量和独立复测三种证据；
- [ ] 能在 [[12-PS1600硬件参数与配置#3. PS1600 关键参数总表]] 中找到相关硬件范围，并知道何时必须回查 TDC。
