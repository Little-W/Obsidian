# V93000 DC 测试方法：Continuity、Leakage 与 IDD

本章给出 continuity、leakage、输入门限、输出电压和供电电流的通用测试方法。完成后，读者应能选择 PPMU、HPPMU 或 DPS，写出 force/measure 表，并设置保护、等待和通过条件。

## 1. Force 与 Measure 四种基本组合

| 模式 | 英文 | 用途 | 主要风险 |
| --- | --- | --- | --- |
| 施加电压、测量电流 | FVMI | leakage、钳位、电源静态电流 | 短路时过流 |
| 施加电流、测量电压 | FIMV | continuity、二极管压降、开路检查 | 开路时电压升高 |
| 施加电压、测量电压 | FVMV | 校核传输或远端电压 | 仪器连接与输入阻抗 |
| 施加电流、测量电流 | FIMI | 特殊受控测量 | 使用较少，需确认仪器支持 |

每个操作必须同时定义 force 值、量程、clamp/compliance、等待时间、采样方式、limits 和资源断开顺序。

## 2. Continuity / Open-Short 测试

Continuity 常在 DUT 主电源关闭时进行，利用 I/O 保护结构或连接电阻判断开路和短路。一个常见方法是 FIMV：对信号 pin 施加小电流并测量电压。

### 2.1 输入表

| 参数 | 占位值 | 来源 |
| --- | --- | --- |
| Pin group | `<all-testable-pins>` | pin plan |
| Force current | `<I_CONT>` | DUT/测试规范 |
| Voltage clamp | `<VCLAMP_LOW/HIGH>` | DUT 绝对最大值与方法 |
| Settle time | `<T_SETTLE>` | 接口与测量评估 |
| Low/High limit | `<V_CONT_LOW/HIGH>` | 好品分布和设计结构 |

### 2.2 执行顺序

1. 关闭 DUT 主电源并确认残余电压已下降。
2. 将无关数字 driver 设为批准的 Hi-Z 状态。
3. 连接 PPMU/HPPMU 到目标 pin。
4. 设置电压 clamp，再施加小电流。
5. 等待稳定并测量电压。
6. 逐 site 记录数值和 pass/fail。
7. 将 force 返回 0，断开测量资源。

开路可能使测量电压接近 clamp，短路可能使电压接近参考地，但不同封装、ESD 结构和连接方式会改变极性与数值。不能照抄固定的 ±100 µA 和二极管压降窗口。

一篇在 V93000 SmarTest 8 上实现 continuity test 的论文说明了用小电流和 voltage clamp 识别开路/短路，并强调 offline verification 不会检查真实电气 limits。[Test Solution Development for Automated Test Equipment](https://ieeexplore.ieee.org/document/9009848)

## 3. Leakage 测试

Leakage 常用 FVMI：给输入 pin 施加规定电压，测量流入或流出 DUT 的小电流。

### 3.1 关键条件

- DUT 电源是否打开；
- 其他 pin 是 Hi-Z、固定状态还是按 pattern 初始化；
- 输入测试电压是低端、高端还是两者；
- PPMU 当前范围是否足够小以获得所需分辨率；
- relay 切换后等待时间是否充分；
- 板级上拉、保护器件和污染电流是否计入。

### 3.2 双点 Leakage 工作表

| 步骤 | Force voltage | Measure current | Limits |
| ---: | ---: | --- | --- |
| 1 | `<VIL_TEST>` | `IIL` | `<IIL_MIN>` 至 `<IIL_MAX>` |
| 2 | `<VIH_TEST>` | `IIH` | `<IIH_MIN>` 至 `<IIH_MAX>` |

如果期望电流为 µA 级，却选择 40 mA range，分辨率和噪声表现可能不合适。量程选择应尽量接近期望值，同时保留异常电流空间和保护。

## 4. 输出 VOH/VOL 参数测试

功能比较只检查输出是否越过 comparator 门限。若要验证 `VOH @ IOH` 或 `VOL @ IOL`，需要按 DUT 规格给输出 pin 提供规定的吸收或供给电流，再测量电压。

操作要点：

1. 用 pattern 把 DUT 输出置为目标逻辑状态。
2. 确认 tester digital driver 已断开，不与 DUT 输出对抗。
3. 使用批准的有源电流单元或 PMU 设置规定电流方向。
4. 等待后测量输出电压。
5. 对照带电流条件的 `VOH_MIN` 或 `VOL_MAX`。
6. 将电流归零并恢复数字模式。

电流正负号必须根据仪器约定写入测试计划，不能只凭自然语言“source/sink”判断。

## 5. IDD 与 DPS 测量

IDD 测试测量 DUT 电源电流，常见类型包括：

| 类型 | DUT 状态 | 关注点 |
| --- | --- | --- |
| Standby IDD | 低活动或待机 | 小电流范围、长稳定时间、板级漏电 |
| Static IDD / IDDQ | 固定逻辑状态 | pattern 停止点、内部状态一致性 |
| Dynamic IDD | 功能 pattern 运行中 | 采样时间、带宽、去耦和峰值 |
| Power-up current | 上电过程 | 限流、斜率、浪涌、保护 |

测量前写明：

- DPS 输出电压、current clamp 和量程；
- force/sense 位置；
- DUT 初始化 pattern；
- pattern 停止或循环状态；
- 测量延迟、积分或采样设置；
- 每个 site 独立供电还是共享；
- limits 是瞬时、平均还是稳定值。

## 6. PPMU、HPPMU 与 DPS 的选择

| 条件 | PPMU | HPPMU | DPS128 |
| --- | --- | --- | --- |
| 每个数字 pin 小电流测量 | 优先 | 需要更高精度/范围时 | 通常不选 |
| 低电流 leakage | 可选，视范围 | 常适合 | DPS 小量程需评估 |
| Continuity | 常用 | 高精度方法可用 | 通常不选 |
| DUT 主电源 | 不适合长时间大电流 | 通常不作为主电源 | 优先 |
| 每 site 大电流 | 不适合 | 不适合 | 按通道和并联方案选择 |

具体范围见 [[12-PS1600硬件参数与配置]] 和 [[13-DPS128与供电资源配置]]。

## 7. 最小在线 Bring-up 顺序

只有在 DUT board、设备和程序均已批准后才能执行：

1. 不装 DUT，检查电源资源 disabled、relay 初态和板级短路。
2. 装入已知良品，先启用单 site。
3. 使用保守 current clamp 和低风险电压上电。
4. 检查 DPS 状态、DUT 端电压与静态电流。
5. 执行短小的 continuity/leakage 项并保存原始数值。
6. 执行基础复位 pattern。
7. 逐步增加测试内容，不一次运行完整量产 flow。
8. 完成后按规定顺序安全下电。

## 8. 故障处理

| 现象 | 可能原因 | 检查 | 处理 |
| --- | --- | --- | --- |
| Continuity 全部接近 clamp | DUT 未接触、force 路径开路或极性错误 | 空板与已知良品对比、接触检查 | 修复接触或方法极性 |
| 某一组 pin leakage 同时偏大 | relay、板级污染或公共外部器件 | 分组断开并测空板 | 清洁或修正外部连接 |
| IDD 到达 current clamp | 短路、上电顺序错误或 clamp 太小 | 立即下电，检查电阻与序列 | 排除硬件问题后再调整 |
| 测量值重复性差 | range、settle、接触、温度或噪声 | 固定条件重复采样 | 调整测量设置或硬件 |
| 多 site 总电流正常但单颗失效 | 使用共享 DPS 无法区分 | 单 site 重测或增加独立资源 | 修改资源方案 |
