# V93000 PS1600 硬件参数与配置

本章集中说明 Pin Scale 1600（PS1600）的数字通道、driver、comparator、每引脚 PMU、板载 ADC 和可选 HPPMU 能力。数值主要取自一份 2025 年公开计量注册资料所列的 V93000 PS1600/CTH 配置，并用 2014 年公开培训幻灯片的产品概览作交叉检查。

> [!danger] 参数适用范围
> 下表不是所有 PS1600、测试头、机架、板卡修订版和软件模式的统一保证值。正式配置必须查当前系统的 model、校准状态与 TDC。DUT 设置还要同时满足器件数据手册和 DUT board 限制。

## 1. PS1600 在系统中的位置

PS1600 是通用数字 pin electronics，一张公开配置中的板卡具有 128 个数字通道。它负责数字驱动、数字比较、每引脚参数测量和部分高压功能。它不能代替专用 DUT 电源板。

Advantest 当前官方产品图已经把后续 Pin Scale 1600B、当前数字/电源/混合信号板卡和多种测试头放在同一平台图中；图中的 1600B 不是本章旧款 PS1600 参数表的直接依据。

## 2. 数字时序能力

| 项目 | 公开资料所列值 | 使用说明 |
| --- | ---: | --- |
| vector period | 2.5 ns～31,250 ns | 对应 400 MHz 到较慢周期 |
| vector period 绝对误差 | ±15×10⁻⁶×T | `T` 为设置的 vector period |
| D1～D8、R1～R8 设置范围 | −4T～+12T | 极端值为 −6.3 µs、+19 µs |
| edge 设置分辨率 | 1 ps | 分辨率不等于绝对准确度 |
| edge 绝对误差 | ±150 ps | 计量资料所列系统条件 |
| 公开产品概览 data rate | 0～1600 Mbit/s | 与模式、许可及 pattern 组织有关 |
| 板卡通道数 | 128 pins/card | 需核对具体硬件版本 |

公开培训幻灯片还列出 400 MHz base rate、每 pin 112 MB memory，并描述 X4 模式。不同资料中的 memory 表述可能按 byte、vector 或模式计算，不能只凭一个数字规划 pattern。

## 3. PS1600 关键参数总表

### 3.1 标准 Driver

| 项目 | 范围/指标 |
| --- | --- |
| 输出电平范围 | −1.5 V～+6.5 V |
| 设置分辨率 | 1 mV |
| 电平绝对误差 | ±5 mV |
| 输出电阻 | 47.5 Ω～52.5 Ω |

标准 driver 的公开动态指标：

| 幅度 | 上升/下降时间上限（10%～90%） | 最小输出脉宽 |
| ---: | ---: | ---: |
| 1.0 V | 0.6 ns | 0.7 ns |
| 1.8 V | 0.7 ns | 0.8 ns |
| 3.0 V | 0.8 ns | 0.9 ns |

### 3.2 宽范围 Driver

| 项目 | 范围/指标 |
| --- | --- |
| `VIL/VIH` 范围 | 0 V～6.5 V |
| `VHH` 范围 | 6 V～13.4 V |
| 设置分辨率 | 1 mV |
| 电平绝对误差 | ±15 mV |
| 输出电阻，0～6.5 V | 45 Ω～55 Ω |
| 输出电阻，6～13.4 V | ≤10 Ω |

宽范围 driver 的公开动态指标按 20%～80% 测量：3 V 时上升时间不超过 9 ns、下降时间不超过 10.5 ns；10 V 时分别不超过 250 ns 和 30 ns。10 V 上升/下降明显不对称，设计时不能按普通高速数字 driver 处理。

公开资料说明宽范围 driver 是每 16 个 pins 中的专用资源，不应假定 128 个通道都能同时输出 13.4 V。

### 3.3 Comparator

| 类型 | 输入或门限范围 | 分辨率 | 绝对误差 |
| --- | --- | ---: | ---: |
| 标准 comparator | −1.5 V～+6.5 V | 1 mV | ±15 mV |
| 宽范围 comparator | −3 V～+13.4 V | 1 mV | 0～8 V 时 ±20 mV；全范围 ±50 mV |
| 差分 comparator | 输入 −1.5 V～+6.5 V；差分门限 −1 V～+1 V | 1 mV | ±15 mV |

### 3.4 有源电流单元

| 项目 | 范围/指标 |
| --- | --- |
| 每通道电流 | −25 mA～+25 mA |
| PS1600 板卡电流合计 | ≤1.6 A |
| 设置分辨率 | 12.5 µA |
| 绝对误差 | ±(设定电流的 1% + 75 µA) |
| 换向电压范围，±1 mA | −1.5 V～+6.5 V |
| 换向电压范围，±25 mA | −1 V～+5.5 V |

“每通道 25 mA”不能直接乘以 128 当作可同时使用值，板卡合计电流已经形成更严格的限制。

### 3.5 每引脚 PMU（PPMU）

| 项目 | 范围/指标 |
| --- | --- |
| Force V，电流不超过 ±1 mA | −2 V～+6.5 V |
| Force V，电流不超过 ±40 mA | −2 V～+5.75 V |
| 电压设置分辨率 | 200 µV |
| 电压测量分辨率 | 75 µV |
| 电流量程 | 2 µA、10 µA、100 µA、1 mA、40 mA |
| 对应电流分辨率 | 1 nA、5 nA、50 nA、0.5 µA、20 µA |

量程决定分辨率与允许电流。continuity 或 leakage 应选能覆盖预期值的最小合适量程，但必须给异常 DUT 留出保护余地。

公开资料给出的 PPMU 电流误差公式如下，`I` 以 µA 代入：

| 量程 | Force I 绝对误差 | Measure I 绝对误差 |
| ---: | --- | --- |
| 2 µA | ±(0.005I + 0.04 µA) | ±(0.005I + 0.01 µA) |
| 10 µA | ±(0.005I + 0.1 µA) | ±(0.005I + 0.05 µA) |
| 100 µA | ±(0.005I + 0.5 µA) | ±(0.005I + 0.2 µA) |
| 1 mA | ±(0.005I + 5 µA) | ±(0.005I + 1.25 µA) |
| 40 mA | ±(0.005I + 50 µA) | ±(0.005I + 50 µA) |

PPMU Force V 的误差为 `±(3 mV + I×1 Ω)`；Measure V 在 0～3.3 V 为 `±(2 mV + I×1 Ω)`，在 −2～0 V 和 3.3～6.5 V 为 `±(4 mV + I×1 Ω)`，其中 `I` 以 mA 代入。

### 3.6 板载 ADC（BADC）

| 模式 | 电压范围 | 输入电阻 | 分辨率 | 绝对误差 |
| --- | --- | --- | --- | --- |
| 标准 | −3 V～+8 V | ≥100 MΩ | 75 µV | ±1 mV |
| 宽范围 | −6 V～+13.4 V | ≥100 MΩ | 150 µV | ±10 mV |

### 3.7 通过 PS1600 使用 HPPMU

| 项目 | 范围/指标 |
| --- | --- |
| 通过 PS1600 pin | −1.5 V～+6 V |
| 通过 utility pogo | −5 V～+8 V |
| 电压设置分辨率 | 250 µV |
| 电流量程 | 5 µA、200 µA、5 mA、200 mA |
| 对应电流分辨率 | 250 pA、6 nA、250 nA、6 µA |

HPPMU 电压误差：通过 PS1600 时为 `±(2 mV + I×1 Ω)`，通过 utility pogo 时为 `±2 mV`，其中 `I` 以 mA 代入。电流误差以 µA 代入：

| 量程/连接 | 绝对误差 |
| --- | --- |
| 5 µA，通过 PS1600 | ±(0.001I + 0.05 µA) |
| 5 µA，通过 utility pogo | ±(0.001I + 0.01 µA) |
| 200 µA | ±(0.001I + 0.2 µA) |
| 5 mA | ±(0.001I + 10 µA) |
| 200 mA | ±(0.001I + 200 µA) |

## 4. 配置计算示例

假设 16 个输出 pin 都使用有源电流单元，每 pin 吸收 8 mA：

```text
I_total = 16 × 8 mA = 128 mA
```

这低于公开资料中的 1.6 A 板卡合计值，但仍要检查：这些 pin 是否位于同一板卡、DUT 总功耗、输出电平条件、热状态和其他同时工作的 pin。

若 1.8 V DUT 的输入条件为 `VIL(max)=0.35VDD`、`VIH(min)=0.65VDD`，则：

```text
VIL(max) = 0.63 V
VIH(min) = 1.17 V
```

可先在离线教学例中选择 driver low 0 V、driver high 1.8 V，再检查过冲、精度和 DUT 未上电条件。comparator 的 `VOL/VOH` 必须来自 DUT 输出规格，不能直接复用 0 V/1.8 V。

## 5. 资源规划表

| DUT 信号 | 需求 | PS1600 资源 | 必查项 |
| --- | --- | --- | --- |
| 普通 1.8 V 输入 | 数字驱动 | 标准 driver | 电压范围、端接、edge rate |
| 12 V 控制输入 | 高压驱动 | 宽范围 driver | 每 16 pins 的位置、输出电阻 |
| 1.8 V 输出 | 数字比较 | 标准 comparator | `VOL/VOH` 与 strobe |
| 双向总线 | 驱动+比较 | driver/comparator | Hi-Z 转换时间 |
| continuity/leakage | Force I / Measure V | PPMU | 量程、clamp、接触 |
| 输出驱动能力 | 有源电流或 PMU | 相应单元 | 电流合计与 DUT 功耗 |

## 7. 常见误用

| 误用 | 为什么不成立 | 正确处理 |
| --- | --- | --- |
| 把 1 ps 当成测量准确度 | 分辨率和绝对误差不同 | 同时查看分辨率、误差和校准 |
| 假定所有 pin 都有 13.4 V driver | 宽范围资源数量有限 | 按板卡位置规划 pin |
| 用 PPMU 当高速 driver | PMU 与数字驱动用途不同 | 按测试类型选择资源 |
| 每 pin 电流直接乘通道数 | 还有板卡合计、功率和热限制 | 计算最严格的同时使用限制 |
| 只检查 tester 范围 | DUT 可能先被损坏 | 取 DUT、板卡和 DUT board 的共同允许区间 |
