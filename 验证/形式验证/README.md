# VC Formal 中文形式验证手册（X-2025.06-SP1）

这是依据用户提供的两本 X-2025.06-SP1 参考手册编写的独立中文教程资料包，包括 21 篇分册 Markdown、A4 合订本 PDF、可编辑 SVG/DOT 插图及 15 个 Tcl 样例与模板。

**建议从 [00_阅读指南.md](00_阅读指南.md) 开始**，再阅读 [形式验证.md](形式验证.md)、[VC_Formal_平台与环境.md](VC_Formal_平台与环境.md) 和 [SVA语法合集.md](SVA语法合集.md)。各应用专题包括 FPV、AEP、FXP、CC、FCA、SEQ、FRV、FTA、FuSa、FSV、DPV 及 FLP。

可直接阅读 [VC_Formal_中文手册_合订本.pdf](VC_Formal_中文手册_合订本.pdf)，或打开 [合订本.md](合订本.md) 搜索全文。对应的源代码和运行说明请见 [案例工程/README.md](案例工程/README.md)，静态验证及版本差异说明见 [质量检查与版本说明.md](质量检查与版本说明.md)。

**请注意：**附带的 Tcl 工程仅进行了离线检查，未使用受许可证保护的 VC Formal 运行；专用应用模板默认防止误执行。正式项目需要核实本机的帮助、版本、授权、时钟复位和规格约束。本包不包含原始专有参考 PDF。

## 目录说明

- `*.md`：按主题拆分的章节、总目录与合订本。
- `插图/`：15 幅 SVG、PNG，子目录 `源码_DOT/` 含可编辑 Graphviz DOT。
- `案例工程/rtl/` 与 `案例工程/formal/`：SystemVerilog RTL 和 SVA。
- `案例工程/scripts/`：基础应用脚本；`案例工程/templates/`：需要填充真实输入的示范模板。
- `脚本与工具/`：校验脚本、排版脚本、插图再生成脚本。
- `附录_修订前笔记/`：压缩包内六份原始 Markdown 笔记的备份。
