## 4. 继承保留的工具文档差异

| 功能 | 文档差异 | 教程处理 |
|---|---|---|
| FCA | 快速参考使用 `FCA`，User Guide 示例使用 `COV` | 优先给出 `set_fml_appmode COV` 并提示核对帮助 |
| FTA | User Guide 不支持 `vcf -fmode FTA` 直接启动 | 先建立 FPV 环境，再切换 FTA |
| FRV | RALF 顶层和 `-parameter` / `-parameters` 示例有差异 | 显式说明地址块顶层并要求核对本地帮助 |
| DPV | HECTOR 新流程开关写法有差异 | 不把两种写法无条件混用 |
| FLP | 该版 User Guide 不支持普通 CC 的延迟连接检查 | 单独说明低功耗检查的限制 |

以上内容依据用户提供的参考资料，不表示本修订版查询并确认了其他版本的最新行为。

## 5. 如何维护正文与工程副本

从手册根目录运行：

```bash
# 检查正文是否已经完整内嵌并与源码一致。
python3 脚本与工具/sync_inline_sources.py

# 修改独立源码后，将新内容同步到已存在的正文代码框。
python3 脚本与工具/sync_inline_sources.py --update

# 构建完成后检查本地引用，避免把尚未生成的 PDF/HTML 当成缺失输入。
python3 脚本与工具/build_pdf.py
python3 脚本与工具/validate_handbook.py
python3 脚本与工具/validate_markdown_tables.py
```

构建依赖 Python 3.10 或更新版本、Pandoc、XeLaTeX、Noto CJK 与 DejaVu 字体；表格检查另需 `markdown-it-py`，Tcl 完整性检查需 `tclsh`。字体未作为独立文件随资料包分发。只重建 Markdown 与离线 HTML 可使用 `build_pdf.py --no-pdf`。
