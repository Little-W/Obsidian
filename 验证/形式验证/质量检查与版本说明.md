# 质量检查与版本说明

> 2026-10-17 · 适用于 VC Formal X-2025.06-SP1 中文手册。

## 1. 文档范围与可信性说明

本书按照上传的 *VC Formal User Guide*（2025 年 9 月，1,168 页）和 *VC Formal Quick Reference Guide*（34 页）编写，汇集了形式验证理论、VC Formal 通用环境、SystemVerilog Assertions（SVA）、12 组主要应用（FPV、AEP、FXP、CC、FCA、SEQ、FRV、FTA、FuSa、FSV、DPV、FLP）、调试方法、验收要点和示例工程。

本书是**独立中文技术教程**，不是所提供版权手册的逐页完整译稿或产品厂商官方指导。参考 PDF 没有被重新分发。不同功能的许可证、引擎可用性和命令开关可能存在产品配置差异，正式项目必须查看其安装版本的 `-help`。

## 2. 已执行的质量检查

- 检查 21 篇核心正文与附册的本地链接及图片相对路径；所有 15 张插图均生成 SVG 与 PNG，并保留对应 DOT 源文件。
- 验证所有案例工程 filelist 引用真实存在的 RTL/SVA 文件。
- 使用 `tclsh` 对所有 Tcl 样例做完整性/括号闭合检查；这是通用 Tcl **语法完整性检查**，不是 VC Formal 命令接口检查。
- 对 RTL/SVA 做有限的静态一致性核查（例如 `module`/`endmodule` 数量），并检查全部 SVG 文件的 XML 结构。
- 使用 Pandoc + XeLaTeX 排版 A4 合订本 PDF；用 Poppler 转换多页为 PNG，抽样查看标题、目录、正文、表格、公式、源码和插图的显示。

**无法执行的检查：**缺少 VC Formal 授权软件，未实际 elaboration、运行 SAT/SMT/符号求解，也没有构造真实的 `report_fv` 运行结果；同样没有进行第三方 SystemVerilog 编译器的完整语言检查。所有工程结果栏均为预期行为。对于专用应用，`templates/` 的 `error` 语句会阻止占位脚本被误执行。

## 3. 与上传参考文档之间的差异

| 功能 | 资料差异 | 当前写法与处理 |
|---|---|---|
| FCA | Quick Reference Guide 的应用模式为 `FCA`，User Guide 相关示例为 `COV` | 以 User Guide `set_fml_appmode COV` 为主要示例并注明差异 |
| FTA | User Guide 不支持 `vcf -fmode FTA` 直接启动 | 先建 FPV，再通过 `set_fml_appmode FTA` 切换 |
| FRV | User Guide 推荐 RALF 加载显式 `-top`，速查示例未示出；UG 中 `-parameters` 与 `-parameter` 示例不同 | 教程推荐指定 RALF 的地址块顶层并现场查询帮助 |
| DPV | User Guide 及快速参考中的 Hector 新流程开关写法不一致 | 提醒本机帮助核对；避免混用 |
| FLP | User Guide 第 1041 页不支持普通 CC 的延迟连接检查 | 低功耗专章显式标注这一限制 |

## 4. 如何重新执行检查并生成 PDF

在具有 Python 3、tclsh 的 Linux 环境运行：

```bash
python3 脚本与工具/validate_handbook.py
```

安装 `pandoc`、`xelatex` 和 Noto CJK 字体以后，从任意工作路径运行：

```bash
python3 脚本与工具/build_pdf.py
```

可重建目录下的 `合订本.md` 和 `VC_Formal_中文手册_合订本.pdf`。要重绘插图，安装 Graphviz 和 Python 图像转换依赖并运行 `脚本与工具/generate_diagrams.py`（请先查该脚本所需的 Python 模块）。

## 5. 正式应用前的验收建议

先按 [总目录](00_阅读指南.md)和 [验证工程与结果判读](验证工程与结果判读.md)建立可追溯的工程清单，再逐条用安装版本的 `help` 核对工具命令；在最小示例上完成首次编译、证明和反例测试。随后替换为真实 RTL、时钟、复位和约束，保留工具日志、版本、许可证环境和审批后的属性覆盖计划。不能因单条断言 `Proven` 就宣布芯片整体功能已经证明。
