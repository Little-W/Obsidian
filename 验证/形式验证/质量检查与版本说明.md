## 5. 维护与重新生成

从手册根目录运行：

```bash
# 检查完整源码是否内嵌，以及正文与独立文件是否一致。
python3 脚本与工具/sync_inline_sources.py

# 编辑独立源码后，将修改同步至正文。
python3 脚本与工具/sync_inline_sources.py --update

# 重新生成 Markdown、离线 HTML 和 PDF。
python3 脚本与工具/build_pdf.py

# 检查资源、源码结构和最终文档版式。
python3 脚本与工具/validate_handbook.py
python3 脚本与工具/validate_no_tables.py
```

构建依赖 Python 3.10 或更新版本、Pandoc、XeLaTeX、Noto CJK 与 DejaVu 字体。无表格检查另需 `markdown-it-py`；Tcl 结构检查需 `tclsh`。字体不作为独立文件随资料包分发。
