# 术语表、应用选择与官方资料定位

> **第 19 册 · 附录索引**　源资料：用户提供的 `VC_Formal_UG.pdf` 与 `VC_Formal_Quick_Reference_Guide.pdf`，均为 **X-2025.06-SP1，2025 年 9 月**。UG 页码与 PDF 页码一致。

## 1. 术语表

- **英文或命令：** Formal verification

  **中文名称：** 形式验证

  **准确理解：** 对数字设计数学模型进行属性或等价性检查

- **英文或命令：** DUT

  **中文名称：** 待验证设计

  **准确理解：** 被检查的 RTL/网表模块或系统

- **英文或命令：** RTL

  **中文名称：** 寄存器传输级描述

  **准确理解：** 主要使用 Verilog/SystemVerilog/VHDL 编写的数字硬件模型

- **英文或命令：** SVA

  **中文名称：** SystemVerilog 断言

  **准确理解：** 描述布尔与时序规则的语言结构

- **英文或命令：** Property

  **中文名称：** 属性

  **准确理解：** 可由工具管理的 assert、assume 或 cover 目标

- **英文或命令：** Assertion

  **中文名称：** 断言

  **准确理解：** DUT 必须满足的规定行为

- **英文或命令：** Assumption

  **中文名称：** 假设

  **准确理解：** 对外部输入与初始条件等的合法性限制

- **英文或命令：** Cover

  **中文名称：** 覆盖目标

  **准确理解：** 搜索某事件/状态是否能够发生

- **英文或命令：** Counterexample

  **中文名称：** 反例

  **准确理解：** 可在当前模型下违反属性的输入/状态路径

- **英文或命令：** Witness

  **中文名称：** 见证

  **准确理解：** 使某目标或性质成立的示范路径

- **英文或命令：** Vacuity

  **中文名称：** 空洞成立

  **准确理解：** 属性成立但关键前提可能从未触发

- **英文或命令：** COI

  **中文名称：** 影响锥

  **准确理解：** 能影响某个目标的逻辑和状态集合

- **英文或命令：** BMC

  **中文名称：** 有界模型检查

  **准确理解：** 展开有限深度搜索违反属性的路径

- **英文或命令：** PDR / IC3

  **中文名称：** 属性引导可达性

  **准确理解：** 用可达集合和归纳不变量等方法完成证明

- **英文或命令：** Induction

  **中文名称：** 数学归纳证明

  **准确理解：** 基础情形与递推情形共同建立全时域性质

- **英文或命令：** Abstraction

  **中文名称：** 抽象

  **准确理解：** 简化设计模型，可能扩大允许行为集合

- **英文或命令：** Proof

  **中文名称：** 证明

  **准确理解：** 在指定模型和前提下建立属性的正确性

- **英文或命令：** Inconclusive

  **中文名称：** 未完成

  **准确理解：** 当前资源或策略尚无明确结论

- **英文或命令：** Noninterference

  **中文名称：** 非干扰

  **准确理解：** 高安全级输入不应影响未授权低安全级输出

- **英文或命令：** Transactional equivalence

  **中文名称：** 事务等价

  **准确理解：** 按事务输入输出阶段对应比较两个实现

- **英文或命令：** Waiver

  **中文名称：** 豁免

  **准确理解：** 经过审查的结果管理，不改变电路正确性

- **英文或命令：** FMEDA

  **中文名称：** 失效模式、影响及诊断分析

  **准确理解：** 对故障后果、诊断能力等的系统分析

- **英文或命令：** UPF

  **中文名称：** 统一电源格式

  **准确理解：** 描述电源域、隔离、保持与供电状态的文件

- **英文或命令：** IP-XACT

  **中文名称：** IP 结构和寄存器描述规范

  **准确理解：** 供工具交换接口与寄存器规范的数据格式

- **英文或命令：** RALF

  **中文名称：** 寄存器抽象层格式

  **准确理解：** 寄存器定义及访问属性的数据格式

## 2. 遇到问题先选哪个应用

- **你的问题：** “这个状态机会不会进入非法状态？”

  **推荐优先应用：** FPV

  **常用补充应用：** AEP

- **你的问题：** “第三方 RTL 有无明显结构性危险？”

  **推荐优先应用：** AEP

  **常用补充应用：** FPV

- **你的问题：** “这个中断线是否按配置接到目的端口？”

  **推荐优先应用：** CC

  **常用补充应用：** FPV

- **你的问题：** “为什么这个信号在启动后可能为 X？”

  **推荐优先应用：** FXP

  **常用补充应用：** AEP / FPV

- **你的问题：** “重写的 RTL 是否行为一致？”

  **推荐优先应用：** SEQ

  **常用补充应用：** FPV

- **你的问题：** “寄存器默认值、W1C 行为是否正确？”

  **推荐优先应用：** FRV

  **常用补充应用：** FPV

- **你的问题：** “未覆盖分支是测试不够还是不可达？”

  **推荐优先应用：** FCA

  **常用补充应用：** FPV

- **你的问题：** “现有断言能否发现故意注入的 RTL 错误？”

  **推荐优先应用：** FTA

  **常用补充应用：** FPV

- **你的问题：** “安全故障能否被诊断发现？”

  **推荐优先应用：** FuSa

  **常用补充应用：** 故障仿真

- **你的问题：** “密钥是否可能影响普通调试输出？”

  **推荐优先应用：** FSV

  **常用补充应用：** FPV

- **你的问题：** “C++ 算法和多拍流水线 RTL 是否一致？”

  **推荐优先应用：** DPV

  **常用补充应用：** SEQ

- **你的问题：** “电源关断后隔离是否正确？”

  **推荐优先应用：** FLP / LPC

  **常用补充应用：** FPV / CC

## 4. 确认过的重要版本差异

1. FCA 是应用名称；该版本 User Guide 使用 `set_fml_appmode COV`，Quick Reference Guide 写为 `FCA`。
2. FTA 一般先在 FPV 会话准备，再通过 `set_fml_appmode FTA` 切换；User Guide 第 65 页说明不能从 `vcf -fmode FTA` 直接启动。
3. DPV 的新 C++ 前端变量写法在两份参考资料中不同，User Guide 第 1069 页给出 `set _hector_comp_use_new_flow true`，需要核验安装环境。
4. 普通 CC 的连接延迟能力不能照搬到 FLP CC：User Guide 第 1041 页明确指出 FLP CC 不支持延迟连接检查。
5. 用户原始笔记包含部分具备本地部署假设的命令，整理后的正式手册在这些位置增加了“教学模板/版本核验/输入文件必要条件”的说明。
