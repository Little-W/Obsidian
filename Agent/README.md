# Agent Studio Workflow / Agent Team 目标设计文档

- 主文档：`Agent_Studio_设计目标与架构构想.md`
- 插图：`assets/`，共 8 张独立 SVG 和 8 张 PNG 预览
- 绘图源代码：`diagrams/generate_svg.py`（Python + svgwrite；可调整矢量图中的箭头、节点、文本和颜色）

建议通过 VS Code、Obsidian 或其他支持 Markdown 相对图片路径的编辑器打开主文档。主文档中的 SVG 可以直接缩放查看而不失真，SVG 本身也是可以编辑的 XML 矢量图。

本材料描述设计目标与架构构想，不包含现有代码完成进度及声称已经通过的实施验收结果。
