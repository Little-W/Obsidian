# 浮点除法与开方实现方法详细设计文档

  

本模块实现了 IEEE754 浮点数的除法（fdiv）和开方（fsqrt）功能，支持单精度和双精度。其核心思想是采用查找表（LUT）获得初始近似值，然后通过牛顿-拉夫森迭代法（Newton-Raphson）进行高精度求解。

## 零、数据预处理详解

  

### 0.1 IEEE 754浮点数格式回顾


**双精度格式（64位）**：

```

| 符号位 | 指数位 | 尾数位 |

| [64] | [63:52] | [51:0] |

| 1位 | 11位 | 52位 |

```

  
**单精度格式（32位）**：

```

| 符号位 | 指数位 | 尾数位 |

| [31] | [30:23] | [22:0] |

| 1位 | 8位 | 23位 |

```

  
### 0.2 除法数据预处理

  
#### 0.2.1 被除数（A）和除数（B）的尾数提取
  
**目标**：将IEEE 754格式的浮点数转换为定点数格式，便于迭代计算。

  **预处理步骤**：

  1. **尾数规格化**：

```verilog

// 代码位置：fp_fdiv.sv 第214-215行

v.qa = {2'h1, v.a[51:0], 2'h0}; // 被除数A的尾数

v.qb = {2'h1, v.b[51:0], 2'h0}; // 除数B的尾数

```
  
2. **格式说明**：

- `2'h1`：添加隐含的1位（IEEE 754规格化数的隐含最高位）

- `v.a[51:0]`：原始52位尾数

- `2'h0`：末尾补零，用于提高计算精度

  
3. **数值范围**：

- 预处理后的qa和qb范围为：[1.0, 2.0) × 2^54

- 即：[0x40000000000000, 0x7FFFFFFFFFFFFF]

  

#### 0.2.2 指数预处理

**指数差值计算**：

```verilog

// 代码位置：fp_fdiv.sv 第217行

v.exponent_fdiv = {2'h0, v.a[63:52]} - {2'h0, v.b[63:52]};

```


**说明**：

- 直接计算被除数指数减去除数指数

- 扩展为14位以防止溢出

- 后续会加上偏置值进行调整

  

#### 0.2.3 倒数查找表索引生成

  **索引提取**：

```verilog

// 查找表索引来自除数的高7位尾数

// 代码位置：fp_fdiv.sv 第219行（查找表访问）

reciprocal_lut[$unsigned(v.b[51:45])]

```

**索引范围分析**：
- `v.b[51:45]`：除数尾数的高7位
- 范围：0到127（2^7 - 1）
- 对应的数值范围：[1.0, 2.0)等分为128个区间
### 0.3 开方数据预处理

  #### 0.3.1 被开方数（A）的特殊处理

  **预处理算法**：

```verilog

// 代码位置：fp_fdiv.sv 第221-225行

v.qa = {2'h1, v.a[51:0], 2'h0};

if (!v.a[52]) begin

v.qa = v.qa >> 1; // 右移一位

end

```

  
**详细说明**：
  
1. **初始尾数构造**：

- 与除法相同，添加隐含1位和末尾补零

- 格式：`{1, 尾数52位, 00}`

  2. **条件右移处理**：

- **判断条件**：`!v.a[52]` - 检查尾数最高位是否为0

- **右移原因**：确保开方运算的数值范围在[1.0, 2.0)内

- **数学意义**：调整尾数使其满足开方算法的输入要求
  
#### 0.3.2 指数预处理（开方）

**指数调整算法**：

```verilog

// 代码位置：fp_fdiv.sv 第226行

v.exponent_fdiv = ($signed({2'h0, v.a[63:52]}) + $signed(-14'd2045)) >>> 1;

```


**详细分析**：

1. **偏置移除**：

- `-14'd2045`：移除双精度偏置值1023，并调整为-2045

- 目的：将指数转换为真实的二进制指数

2. **除以2操作**：

- `>>> 1`：算术右移，相当于除以2

- **数学原理**：√(2^n) = 2^(n/2)

3. **奇偶处理**：

- 当原指数为奇数时，右移会自动处理

- 配合尾数的条件右移，确保算法正确性

#### 0.3.3 倒数根查找表索引生成

  **索引计算**：

```verilog

// 代码位置：fp_fdiv.sv 第227-228行

v.index = $unsigned(v.qa[54:48]) - 7'd32;

v.y = {1'h0, reciprocal_root_lut[v.index], 47'h0};

```

**索引算法说明**：

1. **高7位提取**：`v.qa[54:48]`

- 从预处理后的尾数中提取高7位

- 范围：根据是否右移而不同

1. **偏移量减法**：`- 7'd32`

- **目的**：将索引范围映射到查找表的有效范围[0, 95]

- **原理**：查找表覆盖[1.25, 1.75)范围，需要偏移调整

  

3. **查找表范围**：

- 有效索引：0到95

- 对应数值：[1.25, 1.75)区间的96个等分点

  

### 0.4 预处理对迭代计算的影响

#### 0.4.1 精度保证

**位宽扩展**：

- 原始52位尾数扩展到56位
- 增加的4位提供额外的计算精度
- 减少迭代过程中的舍入误差
#### 0.4.2 数值范围控制

**除法范围**：

- 被除数和除数均在[1.0, 2.0)范围内

- 保证迭代算法的收敛性和稳定性

**开方范围**：

- 通过条件右移确保输入在合适范围

- 配合指数调整保证结果正确性

#### 0.4.3 查找表映射

**精确映射**：

- 预处理后的高位直接作为查找表索引
- 无需额外的地址计算，提高硬件效率
- 查找表覆盖完整的输入范围

## 一、除法实现流程

### 1.1 输入与特殊情况处理

  
**特殊值检测**：

- **sNaN（信令NaN）**: 当任一操作数为sNaN，或∞/∞、0/0时产生

- **qNaN（安静NaN）**: 当任一操作数为qNaN时传播

- **除零异常（DBZ）**: 有限数除以零时产生

- **无穷结果（INF）**: 有限数除以零或无穷除以有限数时产生

- **零结果（ZERO）**: 零除以有限数或有限数除以无穷时产生

  
**异常优先级**：sNaN > qNaN > 除零 > 无穷 > 零

### 1.2 查找表设计原理


**倒数查找表（reciprocal_lut）**：

- **输入范围**：被除数尾数的高7位 `b[51:45]`（范围1.0～2.0）

- **输出精度**：8位精度的倒数近似值

- **数学原理**：对于输入 x ∈ [1,2)，计算 y ≈ 1/x

**LUT数值计算方法**：

```

对于索引 i (0≤i≤127):

input_val = 1.0 + i/128.0 // 将[1,2)区间等分为128份

reciprocal_val = 1.0 / input_val

lut[i] = round(reciprocal_val * 256) // 转换为8位定点数

```

**精度分析**：

- 查找表提供约8位精度的倒数近似
- 最大相对误差约为 ±2^(-8) ≈ ±0.39%
- 为后续牛顿迭代提供良好的初值

### 1.3 牛顿-拉夫森迭代求倒数

**数学原理**：

求解方程 f(y) = 1/y - B = 0，其中B为除数

牛顿迭代公式：y_{n+1} = y_n - f(y_n)/f'(y_n)

**推导过程**：

```

f(y) = 1/y - B

f'(y) = -1/y²

y_{n+1} = y_n - (1/y_n - B)/(-1/y_n²)

= y_n + y_n(1 - B*y_n)

= y_n(2 - B*y_n)

```

  

**三次迭代实现**：

1. **第一次迭代**：

```

e0 = 1 - B*y // 计算误差

y0 = y + y*e0 // 等价于 y*(2-B*y)

```


2. **第二次迭代**：

```

e1 = e0² // 误差平方

y1 = y0 + y0*e1 // 利用误差平方加速收敛

```

  
3. **第三次迭代**：

```

e2 = e1² // 误差四次方

y2 = y1 + y1*e2 // 最终高精度倒数

```


**收敛性分析**：

- 每次迭代误差平方，收敛速度为二次方

- 初始误差 ~2^(-8)，三次迭代后误差 ~2^(-64)

- 足以满足双精度浮点数的精度要求


### 1.4 求商与修正算法

**初步商计算**：

```

q0 = A * y2 // A为被除数，y2为高精度倒数

```

  **余数计算与修正**：

```

r0 = A - q0*B // 计算余数

q0 = q0 + r0*y2 // 使用余数修正商

r1 = A - q0*B // 重新计算余数

```
  
**最终修正**：

```

if (r1 > 0) then q1 = q0 + 1 // 余数为正，商+1

r_final = A - q1*B // 计算最终余数

if (r_final == 0) then q0 = q1 // 余数为零，采用修正值

```

## 二、开方实现流程

### 2.1 查找表设计（reciprocal_root_lut）

**输入处理**：

- 对输入尾数进行预处理，确保在[1,2)范围内
- 如果最高位为0，右移一位并调整指数

**倒数根查找表**：

- **输入范围**：处理后尾数的高7位减去32的偏移量
- **输出精度**：8位精度的倒数根近似值
- **数学原理**：对于输入 x ∈ [1,2)，计算 y ≈ 1/√x

**LUT数值计算方法**：

```

for i in range(96):

input_val = 1.0 + (i+32)/128.0 // [1.25, 1.75)范围

reciprocal_root_val = 1.0 / sqrt(input_val)

lut[i] = round(reciprocal_root_val * 256)

```

### 2.2 牛顿-拉夫森迭代求倒数根

**数学原理**：

求解方程 f(y) = 1/y² - A = 0，其中A为被开方数
  
**推导过程**：

```

f(y) = 1/y² - A

f'(y) = -2/y³

y_{n+1} = y_n - (1/y_n² - A)/(-2/y_n³)

= y_n + 0.5*y_n*(1 - A*y_n²)

= 0.5*y_n*(3 - A*y_n²)

```

**优化迭代序列**：

1. **初始化**：

```

y0 = y * A // 初始近似

h0 = y * 0.5 // y的一半

```

2. **第一次修正**：

```

e0 = 0.5*h0 + y0 // 误差计算

y1 = y0 + y0*e0 // 修正y值

```

3. **第二次修正**：

```

h1 = h0*h0 + e0 // 更新h值

e1 = 0.5*h1 + y1 // 新误差

y2 = y1 + y1*e1 // 再次修正

```

4. **高阶修正**：

```

h2 = h1*h1 + e1 // 最终h值

r0 = A*y2 + y2 // 初步根

y3 = y2*h2 + r0 // 高阶修正

```

### 2.3 求根与精度修正

**最终根计算**：

```

r0 = A*y3 + y3 // 进一步修正

q0 = y3*h2 + r0 // 最终根近似

r1 = A*q0 + q0 // 最终余数

```
  

**修正判断**：

```

if (r1 > 0) then q1 = q0 + 1

r_check = A*q1 + q1

if (r_check == 0) then q0 = q1

```

## 三、硬件实现考量

### 3.1 MAC单元设计

**乘加运算器规格**：

- 输入：两个56位操作数和一个56位累加数

- 输出：110位结果

- 运算模式：加法（op=0）和减法（op=1）

**流水线设计**：

- 每个MAC操作需要一个时钟周期

- 支持valid/ready握手协议

- 迭代过程中依次使用MAC单元

### 3.2 精度与舍入

**规格化处理**：

- 检测结果最高位，必要时左移并调整指数
- 处理指数下溢情况，右移尾数
- 提取Guard、Round、Sticky位用于舍入

**IEEE754舍入模式**：

- 支持向最近偶数舍入、向零舍入等模式
- 正确处理特殊值和边界情况
### 3.3 状态机设计

**主状态**：

- 0：空闲状态，等待输入
- 1：除法迭代状态（11个子状态）
- 2：开方迭代状态（14个子状态）
- 3：规格化处理状态
- 4：输出就绪状态

**子状态计数**：

- 除法：0-10（共11步MAC运算）
- 开方：0-13（共14步MAC运算）
- 每步等待MAC单元ready信号
### 3.4 性能优化

**延迟优化**：

- 除法：约13个时钟周期
- 开方：约16个时钟周期
- 流水线设计支持连续运算

**面积优化**：

- 共享MAC单元减少硬件开销
- 查找表大小优化（128+96项）
- 寄存器复用减少存储需求
  
**功耗优化**：

- 门控时钟设计
- 数据通路使能控制
- 不必要的计算路径关闭
