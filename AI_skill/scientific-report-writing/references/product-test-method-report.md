# 产品测试与验证方法报告编写与审查

本文件适用于仪器、模块、开关矩阵、测试系统及类似产品的测试与验证技术报告。报告以规格核对、测试用例、连接方法和操作条件为核心，但尚不记录实测数据、测试结果或验收结论时，使用本文件。

## 1. 内容范围

- 先确认交付件是测试方法报告、测试记录还是完整测试报告。用户只要求“用例和方法”时，不增加数据记录表、结果汇总、验收输出或结论性章节。
- 章节可按“范围—术语—参考产品或被测产品—总体测试设计—功能与控制—直流性能—交流或电容性能—器件测试用例—参考文献”组织，并根据产品实际能力删减。
- 文献综述、可靠性与维护性、数据记录、结果分析和验收结论只在任务明确要求时设置，不能为了形式完整而补入。
- 参考产品规格与研发样机要求分开表述。专门介绍参考产品的章节只写该产品资料能够证实的组成、功能、规格和成立条件，不混入“本项目”“研发样机应当”等内容。
- 技术参数表优先采用“参数—规定值—成立条件”或其他直接对应关系。没有分组需要时不增加“类别”列。
- “所需设备”和“测量通道安排”分开编排：前者说明仪器、附件及用途；后者只记录实际物理端口、矩阵输入输出和器件端子，不把公式、比较项或数据处理项目列为通道。

## 2. 产品资料和规格核对

- 数值规格优先核对原厂数据手册、用户指南、应用说明和附件手册。中文名称优先核对厂商中文产品页或中文手册；经销商页面和搜索摘要只能作为检索线索。
- 首次出现器件时写清厂商、型号、封装或配置和正式产品类别。节标题可使用简洁的“厂商＋型号＋测试项目”，完整产品名称放在正文首句，避免把测试接法误写成器件名称。
- 没有厂商正式中文名称时，根据原始英文资料和行业常用术语翻译；保留型号及必要英文缩写，不生造简称。产品名称与测试配置必须区分，例如器件本身的产品类别不能由某一种测试接法替代。
- 每个数值都要保留其属性和条件：额定值、最大值、最小值、典型值、补充特性和实测参考值不能互换；温度、偏置、电流、频率、脉冲宽度、占空比、量程和端接条件随数值一并说明。
- 使用“技术规格”“规定值”“最大值”“最小值”“典型值”或“补充特性”等明确说法，不使用含义不清的“保证规格”“完整公开规格”。
- 公式和参数符号按数据手册原文核对。不能用两个彼此独立的极限范围自行相除，替代数据手册单独规定的比值；公式说明应交代每个取值点、测试条件和数值含义。
- 优先采用厂商应用说明、用户指南或设备软件中已有的测试方法。若用例由报告编写者依据多份资料组合设计，应直接说明技术依据，不称为“原厂用例”“原厂参考设计”。
- 技术事实与对应来源就近引用。不要在正文加入“产品宣传资料仅用于……”等面向资料搜集过程的说明；只保留对读者理解规格来源确有必要的内容。

## 3. 测试用例的必要信息

每个用例至少回答以下问题：

1. **测什么**：写明器件型号、封装、端子、额定参数、拟测参数和数据手册条件。
2. **用什么测**：列出仪器和模块的实际型号、可用量程、分辨力或输出能力，以及该设备在本用例中的作用。
3. **还需准备什么**：列出电缆、转接器、校准件、屏蔽箱、低泄漏绝缘材料、插座、夹具、开路板、短路板、温湿度记录仪等关键附件；不得只写主仪器。
4. **怎样连接**：按“仪器通道—矩阵输入—矩阵输出—转接板或夹具—器件引脚”写出完整对应关系，并分别说明信号端、保护端、屏蔽、公共端、Force 和 Sense。
5. **怎样操作**：给出初始状态、输出顺序、扫描范围、步进、限流、量程、积分时间、等待时间、采样次数、复位或断开顺序。
6. **怎样比较**：说明与产品资料规定值、直接连接结果或矩阵接入结果的比较方法，并保持量程、积分时间、等待时间、线缆和夹具条件一致。

测试用例还应遵守以下约束：

- 优先选择有完整数据手册、端子定义和测试条件的实际器件型号。型号必须服务于测试目的，不能仅为使报告显得具体而加入。
- 四线制测量应说明 Force 负责传送激励、Sense 在器件焊盘处检测电位，以及这样连接要排除哪些电缆、连接器或继电器压降；不写含义不明的“检查 Kelvin 连接”。
- 保护端应说明其电位、连接范围及与信号端和机壳的关系。需要保护导体延伸到夹具时，写清其连续路径和终止位置，不使用难以理解的“连续 Guard”。
- 数据手册条件能够复现时，按规定点比较。不能完全复现时，直接说明当前测试用于比较矩阵接入前后的差值或观察变化趋势，不写冗长的“不代表”“不等同于”式免责声明。
- 测试方法报告不虚构测试数据。用户未要求结果记录时，不附空白数据表或“待填写”结果表。

## 4. 中文表达和标题

- 用户的修改意见、示例和写作要求不得进入正文。把“报告中的比较应使用相同条件”改成“实际测试时保持相同条件”。
- 方法段以仪器、端口、器件或操作为主语，直接写技术动作；减少“本报告将……”“下文给出……”等自指表达。
- 删除无技术作用的免责声明和辩解性句子。确需限定适用范围时，正面说明测试条件、用途和可比较对象。
- “被测”和“待测”按语境使用，不使用生硬的“受测”。“原厂”只用于确由制造商提供的资料、附件或应用方法。
- 标题应让非编写者能够理解。避免“接口与组合修正”“端口一致性”“技术链”“测量链”等缺少具体动作或比较对象的标题，改成实际对象，例如“外置传感器接入与误差修正”“不同端口的测量差异”。
- 不用“测点”“承载主功率”等含义不完整的标签；应写清“电压检测端”“主电流通路”“器件阴极”等实际功能。
- 缩略语与正式名称分工明确：常用缩略语可直接使用；可能引起歧义的缩略语在术语章节说明。正文、表格、图题和图内标签使用同一名称。
- 完成内容修改后，扫描 Markdown、SVG、DOCX 提取文本和 PDF 提取文本中的禁用词及旧术语，不能只检查源文档。

## 5. 测量连接框图

- 正式报告中的测试连接图优先采用黑白 SVG；可编辑矢量图是唯一图源，PNG 只作为嵌入和检查产物。
- 将测量仪器、各仪器通道、开关矩阵输入、矩阵输出、转接器、夹具和器件端子分成独立方框或明确分区，不把全部说明塞进一个大方框。
- 物理电缆或导体只表示连接关系时使用无箭头实线。只有方向本身具有技术含义时才使用箭头；双向箭头必须表示确切的双向传输，并在图内说明。虚线必须有图例或紧邻说明，否则改用可直接理解的实线关系。
- Force 与 Sense 分开画出，只在器件焊盘或规定的汇合点相接；保护端、信号端、屏蔽层和保护地不得画成同一节点。
- 连接说明采用端口号、器件引脚和信号功能，不使用笼统的“测点”。切换顺序、仅闭合哪些通路等操作说明放入独立说明框或图下文字，与设备方框和边框保持可见间距。
- 图内文字不得压线、越框或贴近圆角；线条不得穿过文字和其他方框。方框高度不足时扩大方框或调整布局，不通过缩小字号掩盖问题。
- 图题只写图号和图名。插图解读属于正文，使用正文格式，不与图题共用字体、加粗或段落样式。
- 修改 SVG 后重新导出 PNG，并在 PNG 原始尺寸、Word 实际页面尺寸和最终 PDF 页面中分别检查文字、连线、边框和说明框。

更详细的箭头尺寸、端点和重叠检查按 `technical-diagram-review` 技能执行。

## 6. Word 和 PDF 交付

- Markdown 是内容真源，SVG 是插图真源。修改后重新生成 DOCX 和 PDF，不直接修补导出的 PNG 或只修改 Word 外观。
- 正文、列表、题注、表文、参考文献、行内公式和独立公式分别使用对应样式，不能用一个字号覆盖所有对象。
- 图题置于图下，表题置于表上；题注使用正体并与正文解读区分。图、图题和必要引导文字尽量保持在相邻位置。
- 参考文献按正文首次引用顺序编号，产品手册、应用说明和论文使用同一顺序编码。Word 中每个可见引用编号应跳转到对应条目。
- 参考文献保持规定字号和悬挂缩进。末页因单条文献整体换页而产生大面积空白时，先删除重复正文、优化条目换行或允许长条目合理跨页，不缩小正文和标题字号。
- 转换成功后仍须逐页检查 PDF。封面之外不得有空白页；末页、图表前后、标题页尾和不可拆分表格附近不得出现由排版控制造成的大面积空白。
- 最终核对图、表、公式、目录、引用跳转、页码、字体、术语和禁用词，并确认 DOCX 与 PDF 的显示内容一致。

## 7. 交付前快速检查

- 报告范围与用户要求一致，没有自行补回已删除章节。
- 参考产品规格与研发要求没有混写。
- 每个器件名称、型号、封装、数值和测试条件均可由原始资料复核。
- 每个测试用例均写明设备、关键附件、端口对应关系、操作条件和比较方法。
- 通道表只含物理通道，没有“计算项目”等非通道内容。
- 正文没有免责声明式套话、写作指令或资料搜集过程说明。
- 图中没有不明虚线、无定义双向箭头、文字重叠、线条压字或大框堆字。
- Markdown、SVG、DOCX 和 PDF 中不存在未处理的禁用词或旧术语。
- 最终 PDF 没有空白页或内容极少且无必要的末页。
