# UX900 验证工作总结

## 工作概况

本阶段围绕 UX900 CPU 子系统开展基础功能验证与 Feature 覆盖整理工作，完成了时钟复位、启动初始化、接口通路、中断与异常、Cache/MMU、低功耗、PMP 保护、指令功能以及 SDK Demo 移植等方向的验证梳理。整体来看，当前验证内容已覆盖 CPU 启动、运行、访问、调试、中断响应、低功耗唤醒和基础软件适配等关键路径，可支撑 UX900 CPU 基础功能完成情况的阶段性评估。

## 验证内容概览

| 验证方向 | 已完成工作 | 验证结论 |
| --- | --- | --- |

| 接口通路 | 完成 AXI Master、AXI Trace、AXI Slave、CLM/ILM/DLM 访问、JTAG debug、APB debug 等接口验证 | 主要访问通路、Trace 输出和 debug 接口功能符合预期 |

| SDK Demo 移植 | 完成 cache、timer、coremark、dhrystone、eclic、pma、pmp 等 Demo 移植验证 | SDK Demo 可在 UX900 环境下正常运行，基础软件适配通过 |
| 设备空间访问 | 完成多个 memory map/device 空间访问验证 | CPU 可通过 AXI 访问主要 device 地址空间，读写比对正确 |

## 工作总结

本阶段完成了 UX900 CPU 验证 case 与 Feature 覆盖关系的梳理，并对截图中的 Feature 表进行了补全和归类。整理后可以看出，验证工作已覆盖 CPU 子系统的主要功能闭环，包括上电后的启动流程、运行过程中的时钟复位控制、AXI 访问与调试链路、中断异常响应、低功耗进入与唤醒、安全保护机制以及 SDK 示例程序移植。

在启动与复位方面，已验证 CPU 可从 ROM、RAM、ILM 等不同启动介质正常加载执行，同时双核启动流程能够完成 core0 引导、core1 释放复位及启动确认。系统复位、core reset、cc reset 以及 bypass 类控制项也已纳入覆盖，能够支撑后续集成场景下的复位稳定性判断。

在接口与访问方面，已覆盖 AXI Master/Slave 通路、CLM/ILM/DLM 访问、Trace 输出、JTAG debug 和 APB debug 等调试访问能力。相关验证表明 CPU 行为与 Trace 信息基本一致，外部访问和内部存储访问路径能够正常工作，为问题定位和后续 bring-up 提供了基础保障。

在中断、异常与低功耗方面，已完成消息中断、PLIC/ECLIC 中断、异常中断、event 连接、WFI/WFE 以及 deep 休眠唤醒相关验证。验证结果表明，中断触发和服务函数响应路径正常，低功耗状态可进入并能被中断或 event 唤醒，满足 CPU 运行控制和功耗管理的基础要求。

在存储保护、地址映射和指令功能方面，已完成关闭 cache 后访问存储空间、MMU 使能后访问 device、PMP region 保护以及多类指令执行验证。相关结果说明 cache/MMU/PMP 等基础机制可正常生效，常用扩展指令执行结果正确。

在软件适配方面，已完成 SDK 中多个 Demo Case 的移植验证，包括 cache、timer、coremark、dhrystone、eclic、pma、pmp 等基础示例。Demo 程序能够正常运行，说明当前 UX900 验证环境已具备较完整的软件运行与基础功能验证能力。

综合来看，本阶段 UX900 CPU 验证工作已形成较完整的基础功能覆盖，当前可见 case 状态均已完成。后续可继续围绕覆盖率闭环、边界场景、异常注入、长稳压力和系统级联调场景进行补充验证。
