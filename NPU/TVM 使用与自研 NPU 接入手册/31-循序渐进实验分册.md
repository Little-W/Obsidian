## 31.1 实验：固定源码与确认构建

> [!abstract] 目标
> 使用 SSH 取得 v0.24.0，完成最小 LLVM 构建，并证明 Python 加载当前动态库。

### 准备

Linux、Git SSH 权限、CMake 3.24+、Python 3.10+、LLVM 15+。

开始前建立独立工作目录，记录源码提交、构建类型、CMake 选项、Python 包路径、LLVM 版本和目标设备版本。所有命令应能从干净终端重新执行。

### 操作

克隆 `git@github.com:apache/tvm.git`；切到 `v0.24.0`；复制 `config.cmake`；启用 LLVM；构建；安装 tvm-ffi；以 editable 方式安装 Python 包。

建议每完成一个动作就保存对应的 IR、JSON、命令反汇编或运行日志。若实验包含设备执行，固定随机种子并保存输入，不要只保存最终统计数字。

### 预期观察

`git rev-parse HEAD`、`tvm.__file__`、`tvm.base._LOADED_LIBS` 与 `tvm.support.libinfo()` 指向同一构建。

将预期写成自动断言。结构使用 `tvm.ir.assert_structural_equal`，数值按算子规格说明选择位级比较或误差比较，模块加载在新进程完成，性能使用预热与多次重复。

### 失败排查

若提交号正确但库路径错误，先清理 Python 环境中的旧 TVM 包，而不是修改源码。

排查顺序固定为：输入与环境 → 导入后 Relax → 分区后 Relax → 外部产物 → 模块加载 → Tensor 绑定 → 命令 → 设备状态 → 输出。找到第一次偏离预期的位置后再深入。
